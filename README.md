# 动态壁纸平台

这是一个通过兑换码交付静态和动态壁纸的平台。Android 动态壁纸技术闭环已经完成真机验证；正式产品将按 H5 原型、管理后台、数据/API、Flutter 混合 App、Android 上架的顺序实施。

## 已确认产品范围

- 用户从抖音直播间付费后，由客服私发兑换码。
- 用户端不注册账号；兑换后权益绑定设备。
- 一个兑换码可以兑换任意壁纸，额度在生成时形成快照。
- 已获得壁纸在同一设备可重复下载，不再次消耗额度。
- 首发 Android，正式 App 从第一版使用 Flutter 共享层和 Android 原生动态壁纸插件。
- iOS、HarmonyOS 本轮不实现，但首版建立独立平台接口和平台资源变体。

## 当前状态

- Android PoC：应用内预览、系统动态壁纸预览、桌面设置、锁屏设置和姿态视差已验证。
- 产品需求：已冻结。
- 技术架构：已确认采用混合开发。
- H5 功能与交互：已整理。
- H5 设计系统：Token、核心组件和独立预览页已完成并确认视觉方向。
- H5 Mock 原型：首页、分类、详情、兑换、下载、设置、“我的”、教程、客服和两分钟试用已经串通并完成当前轮调整。
- 管理后台：登录、内容、资源版本、发布、兑换码一次性交付、兑换记录和设备权益均已接入真实 API。
- 领域、MySQL 物理模型和 OpenAPI V1 已冻结；Java API 已完成管理内容、设备会话、幂等兑换与权益链路。H5 首页、分类、中文搜索与详情已接入真实公开目录，当前按 [PM-002 开发计划](docs/10-项目管理/PM-002-数据库API与H5联调开发计划.md) 进入 H5 兑换与权益联调。

## Android 技术验证版

当前根目录的 app 和 Gradle 文件属于 Java 技术验证工程。

构建：

    ./gradlew assembleDebug

输出：

    app/build/outputs/apk/debug/app-debug.apk

正式混合工程建立后，该验证代码将迁入 poc/android-java，并把可复用逻辑迁入 Flutter Android 插件。
