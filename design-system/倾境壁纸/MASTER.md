# 倾境壁纸设计系统

**版本：** 0.1
**基准宽度：** 390
**适用端：** H5、Flutter、Android/iOS/HarmonyOS 原生补充界面
**视觉依据：** 用户提供的极简旅行卡片参考图

## 1. 方向

整体为编辑感极简画廊：

- 白色内容面和暖灰页面背景。
- 深黑标题、底部导航和主要按钮。
- 暖黄色作为选中和关键状态。
- 大幅图片、大圆角、柔和下投影。
- 壁纸始终是页面视觉主体。
- 不使用宣传语、价格标签、廉价渐变和大面积玻璃效果。

## 2. 颜色

| Token | 值 | 用途 |
|---|---|---|
| color.ink | #191817 | 标题、黑色导航和主按钮 |
| color.inkSoft | #3F3B37 | 次级标题 |
| color.mutedInk | #6F6A64 | 正文说明 |
| color.subtleInk | #98928B | 辅助信息 |
| color.accent | #F4A91E | 当前选中和重点提示 |
| color.accentSoft | #FFF3D8 | 金刚区暖色底 |
| color.blush | #DE9C95 | 辅助暖粉 |
| color.success | #287A55 | 已获得、已适配和成功 |
| color.danger | #C94943 | 错误与停用 |
| color.background | #F4F3F0 | H5 页面背景 |

| color.outline | #E7E3DD | 边框 |

暖黄色不能同时用于大面积背景和多个按钮。单个视口只保留一个黄色强焦点。

## 3. 字体

中文优先使用系统字体：

    PingFang SC
    Hiragino Sans GB
    Microsoft YaHei
    system-ui
    sans-serif

不加载远程 Web Font。标题使用 700 至 800 字重，正文使用 400 至 500。

| 角色 | 大小 | 字重 | 行高 |
|---|---:|---:|---:|
| 页面标题 | 28 | 800 | 1.25 |
| 分区标题 | 20 | 700 | 1.35 |
| 卡片标题 | 16 | 700 | 1.35 |
| 正文 | 14 | 400 | 1.6 |
| 辅助文字 | 12–13 | 500 | 1.45 |

## 4. 间距与圆角

间距以 4px 为基础单位，页面水平边距 20px。

| 对象 | 圆角 |
|---|---:|
| 小标签 | 999px |
| 表单控件 | 14px |
| 金刚区图标 | 19px |
| 壁纸媒体 | 22px |
| 内容卡片 | 24px |
| 底部面板 | 28px |
| 悬浮导航 | 30px |

## 5. 阴影

- 壁纸卡：0 16px 42px rgba(49, 40, 31, 0.10)。
- 普通卡：0 8px 24px rgba(49, 40, 31, 0.07)。
- 悬浮导航：0 12px 34px rgba(25, 24, 23, 0.18)。

同一卡片不同时使用粗边框和强阴影。

## 6. 组件

### 品牌栏

- 左侧只显示“倾境”。
- 右侧为圆形黑底客服图标。
- 首页右上角使用暖粉到浅橙的低饱和径向渐变，并在进入内容区前自然消失。
- 不显示头像、问候语、宣传词或登录入口。

### 金刚区

- 一级分类在首页首屏可见。
- 图标容器 56px，触控区域至少 56px。
- 选中态使用橙色描边并加粗标签。
- 使用 Lucide SVG 图标，不使用 Emoji。

### 二级分类

- 横向滚动胶囊按钮。
- 第一个固定为“全部”。
- 第一个按钮与分区标题、壁纸列表共用同一条左侧内容边界；仅允许内容向右侧滚动延伸。
- 未选中为白底细边框，选中为黑底白字。
- 不换行，不显示滚动条。

### 壁纸卡

- 双列布局。
- 图片比例 3:4.15。
- 左上角显示资源类型标签。
- 图片下方只显示壁纸名称。
- 所有壁纸列表均不显示平台、已获得、已下载或已设置状态；设备兼容性和可执行操作通过详情页主按钮反馈。
- 不显示价格和虚构下载数量。

### 详情预览

- 顶部依次为返回、标题和橙色描边的“观看教程”按钮。
- 主预览图按壁纸常用的 1:2 比例展示，接近页面满宽。
- 不提供独立的全屏预览按钮，动态效果直接在详情主预览区域展示。
- 详情不展示平台、文件大小、适配标签或文字描述。
- 未获得壁纸时，白色“试用 2 分钟”次按钮位于橙色主按钮上方，两者间距 10px。
- 橙色“下载壁纸”主按钮悬浮在预览图底部，按钮组左右和底部保留 16px 安全距离。
- 动态内容直接替换主预览图；没有动态素材时展示静态封面。

### 两分钟试用

- 只向未获得且兼容的壁纸显示“试用 2 分钟”。
- 试用在 App 内全屏运行，顶部显示剩余时间和关闭按钮，底部显示“结束试用”。
- 试用使用正式动态渲染能力，但不触发兑换、下载正式资源或创建设备权益。
- 用户可提前结束；120 秒到期后自动关闭并清理临时状态。
- 减少动态效果开启时停止自动位移，保留手势或静态预览。

### 主按钮

- 高度 54px，黑底白字，胶囊形。
- 页面只能有一个主要按钮。
- Android 设置选项使用底部面板，不排列三个同级大按钮。
- 禁用态必须说明原因。

### 底部导航

- 固定两个入口：首页、我的。
- 黑色悬浮胶囊，距离左右和底部 20px。
- 当前项为黄色胶囊。
- 未选中项使用白色图标和文字。
- 页面正文必须预留导航和安全区高度。

### 兑换面板

- 从底部弹出，顶部 28px 圆角。
- 兑换码必须有可见标签。
- 验证期间禁用重复提交。
- 成功后主按钮切换为“下载壁纸”。

### 下载面板

- 显示下载进度、资源校验、下载完成和失败重试状态。
- 兑换面板退出后再显示下载面板，两个底部面板不能叠加。
- 下载完成后的主操作为橙色“设置壁纸”。

### 设置位置面板

- 下载完成后从底部弹出，使用单选列表选择设置位置。
- Android 可显示“桌面壁纸”“锁屏壁纸”“桌面和锁屏”。
- 只渲染平台能力层返回的可用选项，Flutter 页面不写死平台判断。
- 用户确认并从系统设置页返回后，成功态显示“壁纸设置成功”。
- 成功态副标题固定为“请返回桌面观看效果”。
- 设置失败时必须显示具体原因；缺少动态壁纸权限时显示橙色“获取动态壁纸权限”按钮。

### 设置教程播放器

- 壁纸详情右上角和客服卡片下方共用“观看设置教程”入口。
- 点击后覆盖当前页面全屏播放，使用 9:16 竖版视频。
- 必须提供播放/暂停、可拖动进度、全屏和关闭控制。
- 播放器关闭后暂停视频并回到原页面位置。

### 教程卡

- 位于“我的”首个内容区。
- 黑色图标块、暖黄局部装饰。
- 不与普通壁纸卡混用视觉样式。

### 我的壁纸

- 已购买壁纸列表只展示封面、资源类型和名称。
- 不展示“已下载”“已设置”等状态，也不放置独立的设置按钮。
- 点击整个列表项进入壁纸详情。
- 页面不展示设备支持编号或设备恢复卡片。

### 微信客服

- 展示二维码、微信号、复制和服务时间。
- 二维码可放大和保存。
- 客服卡片下方显示“观看设置教程”，不再显示设备支持编号卡片。
- 首页顶部与“我的”都能进入。
- 二维码图片必须有替代文字。

## 7. 动效与无障碍

- 普通反馈 140–220ms。
- 面板进入不超过 360ms。
- 不使用会造成布局位移的缩放悬停。
- 触控目标不小于 44px。
- 正文对比度至少 4.5:1。
- 键盘焦点可见。
- 支持 prefers-reduced-motion。
- 375px、390px、430px 无横向溢出。
- H5 壁纸效果预览和界面过渡分离；当前 H5 不实现真实姿态 4D。
