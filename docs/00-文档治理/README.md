# 00-文档治理

本目录管理文档的命名、版本、状态和变更方式。

## 基本规则

- 文档使用 UTF-8 编码和 Markdown 格式。
- 文件名使用清晰的中文主题；带版本的规范使用 `主题-v主版本.次版本.md`。
- 每份正式规范在开头记录状态、负责人、创建日期和最后更新日期。
- 技术验证记录只追加新结论，不改写已经发生的测试事实。
- 架构、格式和接口发生不兼容变化时提升主版本号。
- 产品需求在完成用户、商业、技术三轮诊断并确认范围后进入正式 PRD。

## 文档状态

| 状态 | 含义 |
|---|---|
| 草案 | 可讨论和修改，不能作为验收依据 |
| 已确认 | 范围已确认，可进入实现 |
| 已实施 | 已在代码或环境中落地 |
| 已废弃 | 不再使用，保留历史原因和替代文档链接 |
