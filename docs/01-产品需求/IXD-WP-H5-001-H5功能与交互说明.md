# IXD-WP-H5-001 H5 功能与交互说明

**状态：** 已确认
**版本：** V1.1.0
**日期：** 2026-09-11
**关联需求：** PRD-WP-001

## 1. 产品定位

H5 是正式 App 的交互原型，用 Mock 数据确认界面、导航、状态和文案。它不承担真实动态壁纸设置，也不实现付费和用户登录。

品牌名称固定为“倾境”，首页不展示宣传语、价格、登录头像和商业广告。

## 2. 主导航

底部固定两个入口：

    首页
    我的

壁纸详情、兑换码、设置选项、设计教程和客服为独立页面或弹层，不增加底部入口。

## 3. 首页

页面从上到下：

1. 顶部品牌栏：左侧“倾境”，右侧微信客服入口。
2. 搜索栏：输入壁纸名称、分类或风格，点击“搜索”进入独立结果页。
3. 金刚区：展示一级分类，由管理后台控制名称、上传图标和排序。
4. 二级分类：选择一级分类后，在列表上方横向滚动；第一个选项固定为“全部”。
5. 壁纸列表：双列纵向卡片，持续加载。
6. 底部导航：首页、我的。

壁纸卡片展示：

- 封面。
- 壁纸名称。
- 资源类型：4D、动态或静态。

首页和“我的”的壁纸列表均不显示平台或权益状态。设备不兼容及当前可执行操作由详情页主按钮反馈。

交互：

- 点击一级分类后，切换对应二级分类和壁纸列表。
- 点击二级分类后，只刷新列表，保留一级分类。
- 首页和分类列表顶部均显示搜索栏；搜索结果页保留搜索栏，允许直接修改关键词再次搜索。
- 搜索结果同时匹配壁纸名称、资源类型、一级分类和二级分类名称。
- 点击壁纸卡片进入详情。
- 点击客服图标进入客服页。
- 首版不提供收藏、排行榜和价格展示。

## 4. 壁纸详情

页面从上到下：

1. 返回按钮、壁纸标题和“观看教程”按钮。
2. 1:2 主预览区域。
3. 悬浮在预览区域底部的白色“试用 2 分钟”次按钮和橙色主按钮，两者间距 10px。

详情页不展示平台、文件大小、适配标签或文字描述。当前设备不兼容时，通过禁用主按钮及其按钮文案反馈。

H5 的 4D 主预览使用静态图，不显示额外说明文案，也不模拟陀螺仪渲染。

点击右上角“观看教程”后，打开全屏设置教程播放器。播放器支持播放/暂停、拖动进度、全屏和关闭；与客服页的教程入口共用同一组件与视频资源。

未获得壁纸时显示“试用 2 分钟”。点击后无需兑换码，进入 App 内全屏效果试用并显示 02:00 倒计时；用户可提前结束，倒计时归零后自动关闭并提示“2 分钟试用已结束”。试用不写入已购买列表，不产生设备权益，退出时清理临时试用状态。已获得或设备不兼容时不显示可用的试用入口。

动态效果展示规则：

- 动态素材直接在 1:2 主预览区域内展示，不增加第二个预览模块。
- 支持 MP4/WebM 静音循环视频或审核通过的动图。
- 默认不自动播放声音。
- 用户开启“减少动态效果”时显示首帧。
- 没有预览媒体时整块隐藏，不展示空框。

主按钮状态：

| 权益与本地状态 | 按钮 |
|---|---|
| 未获得 | 下载壁纸 |
| 正在验证兑换码 | 正在验证 |
| 已获得、未下载 | 下载壁纸 |
| 下载中 | 正在下载 43% |
| 已下载 | 设置壁纸 |
| 已设置 | 重新设置 |
| 不兼容 | 当前设备不支持 |

未获得时点击“下载壁纸”，先弹出兑换码面板。

## 5. 兑换码面板

面板从底部弹出，包含：

- 标题“兑换这张壁纸”。
- 兑换码输入框。
- “验证并兑换”按钮。
- 当前结果说明。

流程：

    输入兑换码
      ↓
    验证
      ├─ 成功 → 当前设备获得壁纸 → 开始下载
      ├─ 已获得 → 不扣额度 → 开始下载
      ├─ 无效/停用/过期 → 保留输入并提示
      ├─ 额度耗尽 → 提示联系客服
      └─ 结果未知 → 查询最终结果，禁止重复提交

H5 通过 Mock 场景演示以上结果。

## 6. 下载与设置

H5 模拟状态：

    准备下载
    下载中
    校验资源
    安装完成
    设置壁纸

正式 Android 设置流程：

1. 点击“设置壁纸”。
2. App 查询当前系统实际支持的目标。
3. 展示可用选项：
   - 设为桌面壁纸。
   - 设为锁屏壁纸。
   - 设为桌面和锁屏壁纸。
4. 用户选择后进入 Android 系统预览与确认页面。
5. 用户确认并返回 App。
6. App 查询系统状态；成功则提示“壁纸设置成功”和“请返回桌面观看效果”，取消则保持“已下载”。

如果厂商系统不支持其中某个选项，该项不显示。iOS、HarmonyOS 后续由平台能力返回实际可用操作，不在 Flutter 页面硬编码三项。

如果设置失败，结果面板必须显示平台能力层返回的具体原因。缺少动态壁纸权限时，显示“获取动态壁纸权限”按钮，调用原生能力申请权限；授权成功后继续设置，授权失败或被拒绝时保留原因并允许再次获取。

## 7. 我的

页面从上到下：

1. 页面标题“我的”。
2. 壁纸设计教程大卡片。
3. 已购买壁纸列表。
4. 微信客服大卡片。

壁纸设计教程包含：

- 静态壁纸制作和尺寸。
- Android 4D 分层素材说明。
- 详情页如何直接使用 4D 分层、动态视频或静态原图展示效果。
- 如何将设计素材交给客服。
- 内容授权和禁止上传内容说明。

已购买壁纸列表实际表示“当前设备已获得的壁纸”，不展示付款信息、“已下载”“已设置”等状态，也不显示独立的下载或设置按钮。列表项只展示封面、资源类型和名称，点击整行进入详情后再执行下载或设置。

“我的”页面不展示设备支持编号或设备恢复入口。

## 8. 微信客服

参考考试系统 H5 客服页交互，包含：

- 客服微信二维码。
- 点击放大二维码。
- 保存二维码。
- 微信号。
- 复制微信号。
- 服务时间。
- “观看设置教程”入口，位于客服卡片下方。

客服页和“我的”页面均不展示设备支持编号。点击“观看设置教程”后打开与壁纸详情共用的全屏播放器，支持播放/暂停、拖动进度、全屏和关闭。

首页顶部和“我的”页面都可进入客服。客服是私域交付的核心入口，不隐藏在多级设置页。

## 9. Mock 场景

设计系统和 H5 原型必须支持切换：

- Android 支持 4D。
- Android 只支持静态降级。
- 其他平台能力占位。
- 兑换成功。
- 兑换码无效。
- 兑换码额度耗尽。
- 重复兑换同一壁纸。
- 下载中断和校验失败。
- 已下载和已设置。
- 同设备权益恢复成功。
- 需要客服迁移。
- 空列表和网络失败。
