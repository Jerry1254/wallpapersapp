# 动态壁纸平台产品需求文档

## 一、概述

**文档信息**

| 版本号 | 日期 | 作者 |
|--------|------|------|
| V1.0.0 | 2026-09-10 | — |
| V1.1.0 | 2026-09-11 | — |

V1.1.0 以 [DM-001 统一领域模型](../03-数据设计/DM-001-统一领域模型.md) 为数据语义基线：分类只允许两级且无启停状态；兑换码无启停状态和有效期；当前阶段只支持同设备自动恢复，不展示设备编号，也不实现角色权限与换机迁移。

### 1. 需求背景

- **目标用户现状**：用户在抖音直播间看到壁纸效果，付费后由客服私发兑换码，希望不注册账号即可获得并设置壁纸。
- **核心痛点**：普通图片下载不能直接获得分层视差效果，动态资源又容易出现格式不兼容、重复收费、换包丢失和资源链接泄露。
- **当前问题汇总**：

| 问题点 | 问题描述 | 当前影响 |
|--------|----------|----------|
| 动态效果依赖平台能力 | Android、iOS、HarmonyOS 的壁纸机制不同 | 同一文件不能直接覆盖三个平台 |
| 交付流程割裂 | 购买、收码、下载、设置分散在不同环节 | 用户操作成本高，客服难排障 |
| 无账号但要保留权益 | 用户不登录，仍需识别同一设备和已兑换内容 | 重装后的权益恢复和设备更换需要独立机制 |
| 兑换额度需要冻结 | 新生成兑换码的额度会调整，但历史码不能随默认值变化 | 必须保存每个批次和每个码的额度快照 |
| 数字资源容易被复制 | 固定下载地址、明文资源包和简单抓包会造成泄露 | 需要服务端授权、短时下载票据和包加密 |

### 2. 需求目标

- **业务目标**：
  - 完成“浏览—预览—兑换—下载—设置—再次下载”的 Android 闭环。
  - 让客服可批量生成兑换码，并准确查看每次兑换、设备归属和剩余额度。
  - 从第一版建立 Flutter 共享层与平台原生插件边界，保持 iOS、HarmonyOS 扩展能力。
- **成功标准**：

| 指标 | 当前状态 | 目标状态 |
|------|----------|----------|
| H5 原型 P0 流程覆盖 | 未建立 | 本文 8 项 P0 流程全部可操作并完成人工验收 |
| 兑换额度正确性 | 未实现 | 并发兑换不超发，重复请求不重复扣减 |
| 同设备重复下载 | 未实现 | 已获得壁纸不再要求兑换码 |
| Android 设置闭环 | 单套本地素材已验证 | 在线资源可完成校验、安装、系统预览和设置 |
| 历史码额度稳定性 | 未实现 | 修改默认额度不影响已生成兑换码 |
| 受保护资源地址 | 当前规范包含固定地址 | 公开接口不返回永久资源地址 |

### 3. 需求范围

- **包含**：
  - 移动 H5 原型：分类、列表、详情、预览、兑换、下载和“我的壁纸”。
  - 管理后台原型：分类、壁纸、平台资源、兑换码批次、兑换记录和设备支持。
  - Android 首发 App：Flutter 业务界面与 Android 原生动态壁纸插件。
  - Java API、MySQL、Redis、本地文件存储 Adapter 及统一 OpenAPI 契约；对象存储和 CDN 后续替换接入。
  - 匿名设备注册、同设备权益恢复、资源授权下载和操作审计。
- **不包含**：
  - 在线支付和抖音订单对接。
  - 用户注册、手机号登录和用户账户中心。
  - iOS、HarmonyOS 功能实现和应用市场上架。
  - 对截图、Root、Hook、内存提取的绝对防复制承诺。

## 三、页面结构与导航设计

### 整体导航结构

    用户端：底部双 Tab
    ├─ 首页       → 浏览分类、推荐和壁纸列表
    └─ 我的       → 查看教程、当前设备已购壁纸和微信客服

    管理端：左侧导航
    ├─ 分类管理   → 维护一级分类和排序
    ├─ 壁纸管理   → 维护壁纸、平台资源、版本和发布状态
    ├─ 兑换码     → 生成批次、一次性导出和额度统计
    └─ 兑换记录   → 查询设备权益和兑换流水

### 用户端：首页

**页面职责：** 让用户快速找到可在当前设备使用的壁纸。

**页面元素（从上到下）：**

## 四、功能说明

### 功能 1：壁纸分类与列表

**功能描述**

用户可在首页和分类列表页浏览已发布壁纸，解决直播间用户拿到 App 后无法快速找到目标内容的问题。

**用户流程**

    打开首页
      ↓
    加载分类与推荐内容
      ├─ 成功 → 展示分类和壁纸卡片
      ├─ 数据为空 → 展示空状态和刷新按钮
      └─ 网络失败 → 保留缓存并允许重试
      ↓
    点击分类或壁纸
      ├─ 分类 → 进入分类列表
      └─ 壁纸 → 进入详情页

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| 加载中 | 首次进入或刷新 | 请求成功或失败 | 骨架屏 |
| 有内容 | 返回已发布内容 | 刷新或离开 | 分类和卡片 |
| 空内容 | 当前分类无内容 | 更换分类或刷新成功 | 空状态 |
| 缓存内容 | 网络失败且本地有缓存 | 联网刷新成功 | 旧内容及离线提示 |
| 加载失败 | 网络失败且无缓存 | 重试成功 | 错误状态 |

**字段规范**

本功能无用户输入字段，仅展示系统生成或已保存数据。

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | 暂时没有可用壁纸 |
| 加载中 | 正在加载壁纸 |
| 操作成功 | 已更新 |
| 操作失败 | 加载失败，请重试 |
| 权限不足 | 当前内容暂不可用 |
| 网络异常 | 网络不可用，已展示最近内容 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 网络断开 | 列表请求失败 | 优先读取已过期缓存并标记 | 网络不可用，已展示最近内容 |
| 数据为空 | 无已发布内容 | 展示空状态 | 暂时没有可用壁纸 |
| 操作超时 | 20 秒无响应 | 取消请求并提供重试 | 加载超时，请重试 |
| 权限不足 | 内容已下架或渠道不可见 | 从列表移除并刷新 | 当前内容暂不可用 |

### 功能 2：详情、动态预览与适配

**功能描述**

用户可在壁纸详情页查看接近手机比例的完整预览。服务端仍按当前平台返回可用变体；界面通过主按钮状态处理设备不兼容，不额外展示平台和适配说明区。

**用户流程**

    进入壁纸详情
      ↓
    服务端返回当前平台可用变体
      ├─ 支持动态 → 允许进入动态预览
      ├─ 仅支持静态 → 展示静态效果和说明
      └─ 完全不支持 → 禁止下载并展示原因
      ↓
    启动预览
      ├─ 传感器可用 → 根据手机倾斜渲染
      ├─ 权限未授予 → 请求权限或使用拖动模拟
      └─ 性能不足 → 自动降级为低质量预览
      ↓
    未获得用户点击“试用 2 分钟”
      ├─ 打开 App 内全屏效果试用
      ├─ 显示 02:00 倒计时，可提前结束
      └─ 到期 → 自动关闭试用并清理临时资源，不创建设备权益

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| 检测中 | 打开详情 | 能力检测完成 | 检测提示 |
| 可动态使用 | 有匹配平台变体和能力 | 资源状态变化 | 预览、下载按钮可用 |
| 静态降级 | 只有静态变体或性能不足 | 用户返回 | 静态预览及说明 |
| 不兼容 | 无匹配变体 | 内容补齐或换设备 | 禁用下载 |
| 预览中 | 详情页加载动态预览 | 离开详情或发生错误 | 主预览区域内显示视差效果 |
| 预览失败 | 资源或渲染失败 | 重试成功 | 封面和错误提示 |
| 试用中 | 未获得用户点击试用 | 提前结束或倒计时归零 | 全屏效果及剩余时间 |
| 试用结束 | 用户结束或 120 秒到期 | 返回详情 | 提示试用已结束 |

**字段规范**

本功能无用户输入字段，仅展示系统生成或已保存数据。

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | 暂无可预览资源 |
| 加载中 | 正在准备预览 |
| 操作成功 | 预览已就绪 |
| 操作失败 | 预览加载失败，请重试 |
| 试用入口 | 试用 2 分钟 |
| 试用结束 | 2 分钟试用已结束 |
| 权限不足 | 允许使用动作与方向传感器以体验倾斜效果 |
| 网络异常 | 网络异常，暂时使用封面预览 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 网络断开 | 预览资源未缓存 | 使用封面 | 网络异常，暂时使用封面预览 |
| 数据为空 | 平台变体缺失 | 禁止下载 | 当前设备暂不支持这张壁纸 |
| 操作超时 | 资源 20 秒未完成 | 取消并可重试 | 预览准备超时 |
| 权限不足 | 传感器权限被拒绝 | 使用手势模拟，不阻断浏览 | 可拖动屏幕查看效果 |

### 功能 3：兑换码与设备权益

**功能描述**

用户可在壁纸详情页输入任意有剩余额度的兑换码，为当前设备获得一张壁纸；同一设备再次进入或重新安装后，使用设备凭据重新关联并自动恢复权益。

**用户流程**

    未获得壁纸时点击下载
      ↓
    输入兑换码并提交
      ↓
    服务端执行幂等事务
      ├─ 当前设备已拥有 → 不扣额度，直接返回权益
      ├─ 码存在且有余额 → 扣减 1 个额度并创建设备权益
      ├─ 码不存在 → 拒绝兑换
      ├─ 码额度已用完 → 拒绝兑换

**用户流程**

      ↓

      ↓

      ├─ 已保存 → 关闭明文交付页面

| 已耗尽 | 所有码 `usedQuota = totalQuota` | 只读展示 100% |

    查看兑换结果、额度变化、匿名设备内部标识和权益
      ├─ 同设备重复获得 → 确认 delta 为 0
      ├─ 新设备首次获得 → 确认 delta 为 1
      └─ 失败事件 → 查看稳定错误码与请求编号

**展示状态**

| 状态名称 | 进入条件 | 用户可见表现 |
|----------|----------|--------------|
| 查询中 | 请求尚未完成 | 表格加载状态 |
| 有记录 | 返回至少一条事件 | 记录列表与详情 |
| 无记录 | 条件下没有事件 | 保留筛选条件的空状态 |
| 查询失败 | 网络或服务异常 | 错误提示和重试按钮 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|--------|------|----------|----------|----------|----------|
| 兑换码尾号 | 文本 | 否 | 4 至 8 位 | 只允许有效字符 | 请输入有效码尾号 |
| 壁纸 | 字符串 ID | 否 | — | 必须为存在的壁纸 | 请选择有效壁纸 |
| 结果 | 枚举 | 否 | — | 只接受稳定兑换结果枚举 | 请选择有效结果 |
| 开始/结束时间 | 日期时间 | 否 | — | 开始不得晚于结束 | 请选择有效时间范围 |

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | 没有符合条件的兑换记录 |
| 加载中 | 正在查询兑换记录 |
| 操作成功 | 已更新兑换记录 |
| 操作失败 | 查询失败，请重试 |
| 会话失效 | 登录已失效，请重新登录 |
| 网络异常 | 网络异常，请稍后重试 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 网络断开 | 查询请求失败 | 保留筛选条件并允许重试 | 网络异常，请稍后重试 |
| 数据为空 | 查询无结果 | 保留筛选条件 | 没有符合条件的记录 |
| 操作超时 | 20 秒无响应 | 取消请求并允许重试 | 查询超时，请重试 |
| 会话失效 | 管理员会话无效 | 清除本地会话并返回登录页 | 登录已失效，请重新登录 |
| 数据变化 | 查询期间发生新兑换 | 下次刷新读取最新事实 | 数据已更新，请刷新 |
