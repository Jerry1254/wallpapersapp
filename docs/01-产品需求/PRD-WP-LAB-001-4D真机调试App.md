# 倾境壁纸 4D 真机调试 App 产品需求文档

## 一、概述

**文档信息**

| 版本号 | 日期 | 作者 |
|---|---|---|
| V 1.0.0 | 2026-09-16 | — |

### 1. 需求背景

- **目标用户现状**：内部 4D 壁纸调试人员已经可以在 Web 模拟器制作 v2 配置，但 Web 无法完整还原真实手机尺寸、握持姿态与传感器反馈。
- **核心痛点**：必须反复修改、导出、上传和安装才能判断真机效果，调参链路过长。
- **当前问题汇总**：

| 问题点 | 问题描述 | 当前影响 |
|---|---|---|
| 真机反馈缺失 | Web 模拟器只能模拟倾斜，无法代替实际传感器 | 位移、缩放和视觉舒适度需要多轮返工 |
| 修改链路过长 | 每次调整都要回到 Web 重新导出 ZIP | 无法边倾斜手机边调整参数 |
| 正式 App 不适合编辑 | 正式详情页面向普通用户 | 调试功能不能进入正式用户流程 |

### 2. 需求目标

- **业务目标**：
  - 在真实 Android 手机上完成 4D 参数调整、预览和保存。
  - 复用现有 App 全部页面与能力，只替换 `lab` 构建中的 4D 详情页。
  - 保存只生成新的配置版本，不改图片、图层顺序或正式 App 页面。
- **成功标准**：

| 指标 | 当前状态 | 目标状态 |
|---|---|---|
| 真机调参链路 | Web 修改后重新导出、上传、安装 | 进入详情后直接调整并实时预览 |
| 参数输入 | Web 操作 | 真机滑动与精确数字输入均可用 |
| 配置安全 | 人工替换完整资源 | 保存生成新版本，旧版本可回滚 |
| 正式 App 影响 | 无调试能力 | 正式 App 行为和页面保持不变 |

### 3. 需求范围

- **包含**：独立 `lab` 安装包、全屏 4D 调试页、水平/垂直独立运动强度、每层初始位置修正、取消/复位、管理员整体保存、配置版本与冲突保护。
- **不包含**：增删或替换图片、图层排序、在预览画布上直接拖动图层、动态壁纸/静态壁纸参数编辑、正式 App 页面改造。

## 三、页面结构与导航设计

### 整体导航结构

```text
现有底部双 Tab
├─ 首页 → 完全复用正式 App 首页、搜索、分类和列表
│  └─ 4D 壁纸 → 全屏 4D 调试页
│  └─ 动态/静态壁纸 → 复用正式 App 详情页
└─ 我的 → 完全复用正式 App
```

### 全屏 4D 调试页

**页面职责：** 在真实手机姿态下查看完整画面，并在同一页面完成参数调整和保存。

**页面元素（从上到下）：**

| 区域 | 内容 | 显示条件 |
|---|---|---|
| 全屏预览画布 | 当前正式图层与临时配置的实时 4D 渲染 | 始终显示，延伸至系统状态栏和导航栏后方 |
| 顶部悬浮栏 | 返回、壁纸名称、传感器状态、版本状态、右上角保存、隐藏控件 | 控件可见时显示；保存是整页唯一保存入口 |
| 收起控制条 | 当前图层、参数摘要、“调整参数”按钮 | 参数面板收起时显示 |
| 参数面板 | 只读图层条、当前图层参数、底部高级设置 | 参数面板展开时覆盖屏幕下部，预览仍在背后运行 |
| 唤回按钮 | “点击显示控件” | 用户隐藏全部控件后显示半透明轻量入口 |

**本页面不展示：** 购买、下载进度、教程、设置系统壁纸、素材上传、图层增删和图层拖拽排序。初始位置只通过明确的 X/Y 参数调整，不允许直接拖动画布改变图层位置。

### 参数面板结构

```text
无文字关闭按钮；点击面板外预览区域或点击顶部拖动条收起
├─ 图层选择：01、02……NN（只读顺序，不可拖拽）
├─ 当前图层：名称、类型、参数摘要、复位本层
├─ 运动方向：跟随 / 反向 / 固定
├─ 水平运动强度：动态范围滑块 + 数字输入 + %
├─ 垂直运动强度：动态范围滑块 + 数字输入 + %
├─ 初始水平位置：有符号动态范围滑块 + 数字输入 + %
├─ 初始垂直位置：有符号动态范围滑块 + 数字输入 + %
├─ 缩放：滑块 + 数字输入
├─ 不透明度：滑块 + 数字输入 + %
├─ 混合模式：正常 / 滤色 / 叠加
└─ 全局高级设置：水平/垂直最大倾斜角度（全部图层共用，默认均为 75°）
```

### 独立页面 / 弹窗

| 页面/弹窗名称 | 触发条件 | 与主导航的关系 |
|---|---|---|
| 管理员登录页 | 首次保存或管理员会话失效 | 覆盖调试页；成功后返回并继续保存 |
| 返回保存询问 | 有未保存修改时点击返回 | 提供“保存并返回”“不保存并返回”“继续调整” |
| 保存确认弹窗 | 有未保存修改时点击右上角保存 | 确认后整体提交全部参数 |
| 版本冲突提示 | 保存时后台版本已变化 | 覆盖参数面板，提供刷新配置入口 |
| 保存结果提示 | 保存成功或失败 | 页面内短提示，不离开调试页 |

## 四、功能说明

### 功能 1：独立 Lab 构建

**功能描述**

项目增加 `lab` 构建类型。它与正式 App 共用源码、UI、API 和原生渲染器，仅在打开 4D 详情时切换到全屏调试页。

**用户流程**

```text
安装“倾境壁纸·4D调试”
  ↓
进入现有首页和列表
  ↓
点击 4D 壁纸 → 全屏调试页
点击动态/静态壁纸 → 现有详情页
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 正常浏览 | Lab App 启动 | 点击 4D 内容 | 与正式 App 一致 |
| 4D 调试 | 打开 4D 内容 | 返回列表 | 全屏调试页 |

本功能无用户输入字段，仅由构建配置决定应用名称、应用 ID 和页面路由。

**文案规范**

| 场景 | 文案内容 |
|---|---|
| 应用名称 | 倾境壁纸·4D调试 |
| 非 4D 内容 | 复用正式 App 原文案 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 设备不支持 | 无可用姿态传感器 | 保留触摸预览 | 此设备未检测到姿态传感器，可拖动画面检查参数 |

### 功能 2：全屏实时预览与面板

**功能描述**

进入页面后立即加载当前配置。预览铺满全屏并持续读取姿态；面板展开、收起或滚动时渲染不暂停。

**用户流程**

```text
打开 4D 调试页
  ↓
加载资源与当前配置
  ├─ 成功 → 全屏实时预览
  ├─ 传感器不可用 → 触摸预览
  └─ 资源失败 → 错误页并允许重试
  ↓
点击“调整参数” → 展开悬浮面板
  ├─ 点击面板外预览区域或顶部拖动条 → 返回全屏观察
  └─ 点击“隐藏控件” → 只保留画面与唤回按钮
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 加载中 | 页面打开 | 首帧成功/失败 | 全屏封面与加载提示 |
| 控件收起 | 首帧成功或收起面板 | 展开/隐藏 | 完整画面、顶部栏和底部控制条 |
| 控件展开 | 点击调整参数 | 点击面板外预览区域、顶部拖动条或隐藏控件 | 下部悬浮面板，画面继续运动；不显示“收起”文字按钮 |
| 沉浸观察 | 点击隐藏控件 | 点击唤回 | 只有全屏壁纸效果 |
| 渲染失败 | 配置或资源不可用 | 重试成功 | 明确错误和重试按钮 |

本功能无存储字段；面板高度、滚动位置和控件显隐只在当前页面生命周期内保留。

**文案规范**

| 场景 | 文案内容 |
|---|---|
| 加载中 | 正在加载真机效果… |
| 传感器正常 | 姿态响应正常 |
| 触摸回退 | 未检测到姿态传感器，可拖动画面预览 |
| 渲染失败 | 当前 4D 资源无法预览 |
| 重试 | 重新加载 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 页面退到后台 | App 失去前台 | 暂停传感器与绘制，保留临时参数 | 返回后继续预览 |
| 内存不足 | 原图无法完整解码 | 停止本次预览，不静默降分辨率 | 原图无法在当前设备完整加载 |
| 网络中断 | 尚未下载资源 | 保留封面并允许重试 | 网络不可用，请连接后重试 |

### 功能 3：参数调整

**功能描述**

用户从只读图层条选择一个图层，通过滑块快速试值，通过数字框精确输入。有效修改只送入当前手机的原生渲染器进行临时预览，不请求后台、不逐项保存，也不重新下载图片。

**用户流程**

```text
展开参数面板
  ↓
选择图层
  ↓
拖动滑块或输入数值
  ├─ 合法 → 立即更新预览并标记“未保存”
  └─ 非法 → 保留上一个合法值并显示字段错误
  ↓
收起面板 → 全屏倾斜检查
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 原始值 | 尚未修改 | 任一字段变化 | 状态显示“已保存” |
| 编辑中 | 存在有效差异 | 保存/全部恢复 | 状态显示“未保存” |
| 输入错误 | 数字框内容非法 | 改为合法值/失焦恢复 | 字段红色提示，预览沿用上一合法值 |
| 实时应用失败 | 原生渲染拒绝配置 | 复位或重新输入 | 本次值不生效并提示原因 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| 水平最大倾斜角度（全局） | 数字 | 是 | 6 字符 | `1～75` 度；默认 `75`；全部图层共用，决定左右倾斜达到满幅水平运动所需角度 | 请输入 1～75° |
| 垂直最大倾斜角度（全局） | 数字 | 是 | 6 字符 | `1～75` 度；默认 `75`；全部图层共用，决定上下倾斜达到满幅垂直运动所需角度 | 请输入 1～75° |
| 图层方向 | 枚举 | 是 | — | 跟随、反向、固定 | 请选择运动方向 |
| 水平运动强度 | 数字 | 是 | 12 字符 | 非负有限数；无产品上限；100 表示满幅水平倾斜时移动一屏宽 | 请输入不小于 0 的有效数字 |
| 垂直运动强度 | 数字 | 是 | 12 字符 | 非负有限数；无产品上限；100 表示满幅垂直倾斜时移动一屏高 | 请输入不小于 0 的有效数字 |
| 初始水平位置 | 有符号数字 | 是 | 12 字符 | 有限数；0 为素材中心；负数向左、正数向右；100 表示一屏宽 | 请输入有效的水平位置 |
| 初始垂直位置 | 有符号数字 | 是 | 12 字符 | 有限数；0 为素材中心；负数向上、正数向下；100 表示一屏高 | 请输入有效的垂直位置 |
| 缩放 | 数字 | 是 | 6 字符 | `1.00～1.50` | 请输入 1.00～1.50 |
| 不透明度 | 数字 | 是 | 6 字符 | UI 输入 `0～100%`，配置保存为 `0～1` | 请输入 0～100% |
| 混合模式 | 枚举 | 是 | — | 正常、滤色、叠加，对应 `normal/screen/add` | 请选择混合模式 |

水平和垂直运动滑块默认显示 `0～100%`。当输入值超过当前范围时，滑块上限扩展到下一个整百，例如输入 `450` 后显示 `0～500%`，不裁剪用户输入。初始位置滑块默认显示 `-100%～100%`，超出后按当前绝对值向下一个整百对称扩展。

每层共用一个 `direction`，但水平与垂直运动强度独立。渲染位置按对应屏幕轴计算：

```text
X = 初始水平位置 × 屏幕宽度 - 方向符号 × 水平倾斜进度 × 水平运动强度 × 屏幕宽度
Y = 初始垂直位置 × 屏幕高度 + 方向符号 × 垂直倾斜进度 × 垂直运动强度 × 屏幕高度
```

配置字段使用 `offsetXPercent`、`offsetYPercent`、`initialOffsetXPercent`、`initialOffsetYPercent`。原单值 `offsetPercent` 在尚未上线阶段直接移除，不保留双写或旧格式兼容。

水平和垂直最大倾斜角度属于配置级全局参数，不属于任何图层，默认均为 `75°`。切换图层不会改变它们，“复位本层”不会恢复它们；放弃整份修改时才恢复为基础版本的值。配置的 `motion` 使用 `maxAngleX` 和 `maxAngleY`，原单值 `maxAngle` 在尚未上线阶段直接移除。

**文案规范**

| 场景 | 文案内容 |
|---|---|
| 未保存 | 未保存 |
| 当前图层 | 图层 03 · 人物 |
| 背景层 | 背景层 · 最后一层 |
| 固定方向 | 固定后位移不参与渲染 |
| 输入失败 | 保留上一个有效值 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 输入为空 | 清空后失焦 | 恢复上一个合法值 | 请输入有效数字 |
| 数值超出字段范围 | 角度、缩放或透明度越界 | 不提交到渲染器 | 显示对应范围 |
| 连续快速拖动 | 滑块频繁变化 | 每帧合并为最新值 | 画面保持响应，不弹提示 |

### 功能 4：图层复位与退出保护

**功能描述**

用户可以复位当前图层。有未保存修改时点击返回，页面询问是否整体保存；没有修改时直接返回。

**用户流程**

```text
存在未保存修改
  ↓
当前图层复位 → 恢复该层所有字段
点击返回 → 保存询问
  ├─ 保存并返回 → 确认后整体保存，成功后退出
  ├─ 不保存并返回 → 恢复基础配置并退出
  └─ 继续调整 → 关闭弹窗并保留临时修改
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 无修改 | 临时配置等于基础版本 | 修改参数 | 返回直接退出，右上角显示已保存且不可点击 |
| 有修改 | 任一有效参数变化 | 保存/放弃 | 版本行显示有修改，右上角保存变为可点击 |
| 返回询问 | 有修改时点击返回 | 保存并返回/不保存并返回/继续调整 | 是否保存本次修改弹窗 |

本功能无新增存储字段，所有复位均以进入页面时取得的基础配置为准。

**文案规范**

| 场景 | 文案内容 |
|---|---|
| 返回标题 | 保存本次修改？ |
| 返回说明 | 当前修改尚未保存。你可以整体保存后返回，或者放弃修改直接返回。 |
| 保存返回 | 保存并返回 |
| 放弃返回 | 不保存并返回 |
| 继续按钮 | 继续调整 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 恢复渲染失败 | 原始配置无法重新应用 | 重新加载原资源 | 正在重新加载原配置… |

### 功能 5：保存与配置版本管理

**功能描述**

管理员完成全部图层和场景参数调整后，只点击一次“保存全部参数”。客户端把当前完整 v2 `config.json` 和基础配置版本作为一个请求提交。服务端复用原封面与图层创建一个新配置版本，构建新的安全资源版本并切换为当前版本。整个配置原子保存，不能出现某个字段或某个图层单独保存成功；底层不覆盖旧签名资产。

**用户流程**

```text
完成所有参数调整
  ↓
点击右上角“保存”
  ↓
弹窗确认“保存全部参数？”
  ↓
检查管理员会话
  ├─ 未登录/过期 → 登录 → 返回继续保存
  └─ 已登录 → 提交完整配置与基础版本
                 ├─ 成功 → 新版本成为当前版本，页面转为已保存
                 ├─ 版本冲突 → 提示刷新，不覆盖他人版本
                 └─ 网络/服务失败 → 保留本地修改，可重试
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 不可保存 | 没有修改或存在字段错误 | 产生合法差异 | 保存按钮禁用 |
| 可保存 | 存在合法差异 | 点击保存 | 保存按钮可用 |
| 保存中 | 请求已提交 | 成功/失败/冲突 | 按钮显示“正在保存”，禁止重复提交 |
| 保存成功 | 新版本已成为当前版本 | 再次修改 | 显示“已保存 · v{N}” |
| 保存失败 | 网络或服务失败 | 重试/取消 | 保留所有临时修改 |
| 版本冲突 | 基础版本不再是当前版本 | 刷新/取消 | 禁止覆盖，提示当前最新版本 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| wallpaperId | ID | 是 | 19 字符 | 正整数 | 壁纸信息无效 |
| baseResourceVersionId | ID | 是 | 19 字符 | 必须仍是当前配置版本 | 配置已经被其他人更新 |
| config | JSON | 是 | 64 KiB | `formatVersion=2`；画布和图层索引与基础包完全一致 | 配置结构发生变化，无法保存 |

服务端保存时只允许算法参数变化。以下内容必须与基础包一致：`formatVersion`、`canvas.width/height`、图层数量、`layers[].index`、素材资产、文件角色与图层顺序。

页面不存在底部操作栏，也不存在字段级、参数级或图层级保存按钮。所有滑块和输入框只修改同一份本地临时配置；右上角是整页唯一保存入口。点击后必须经过确认弹窗，再一次提交场景参数以及全部图层参数。请求任何一步失败时，后台继续使用旧版本，手机保留整份临时修改供用户重试。

**文案规范**

| 场景 | 文案内容 |
|---|---|
| 保存确认标题 | 保存全部参数？ |
| 保存确认说明 | 场景参数和所有图层参数将整体保存为一个新版本。 |
| 保存中 | 正在保存全部参数… |
| 保存成功 | 全部参数已保存为版本 {versionNo} |
| 保存失败 | 保存失败，本次修改仍已保留 |
| 权限不足 | 管理员登录后才能保存配置 |
| 会话过期 | 管理员会话已失效，请重新登录 |
| 版本冲突 | 配置已被其他设备更新，请刷新后继续 |
| 网络异常 | 网络不可用，本次修改仍已保留 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 网络断开 | 保存请求未成功 | 保留内存中的完整修改 | 网络恢复后可重新保存 |
| 操作超时 | 15 秒无响应 | 结束等待但不清除修改 | 保存超时，请重试 |
| 权限不足 | 未登录或会话过期 | 打开管理员登录页 | 登录后继续保存 |
| 版本冲突 | 后台当前版本变化 | 不自动合并、不覆盖 | 刷新最新配置后重新调整 |
| 构建失败 | 新安全资源生成失败 | 服务端不切换当前版本 | 新版本构建失败，原版本仍在使用 |

## 五、版本规则

### App 版本

| 应用 | 应用名称 | 应用 ID | 版本规则 |
|---|---|---|---|
| 正式 App | 倾境动态壁纸 | `com.qingjing.bizhi` | 正式版本独立递增，不因 Lab 页面单独升级 |
| Lab App | 4D壁纸·本地测试 | `com.qingjing.bizhi.lab` | 独立从 `0.1.0+1` 递增 |

Lab 构建使用同一 Git 提交。正式 App 与 Lab App 的公共代码修改共享；Lab 详情页通过构建模式隔离，不复制目录或维护第二套业务代码。

### 配置版本

- 每次保存创建新的不可变配置版本和资源版本。
- 新版本创建、签名构建和切换全部成功后才成为当前版本。
- 旧版本不删除，供管理后台回滚和审计。
- 同一基础版本只允许一个保存请求成功，后续请求返回版本冲突。
- App 页面显示当前版本号，不向用户暴露资产路径、签名或内部 SHA。

## 六、页面视觉规则

- 沿用现有倾境壁纸黑色、白色和品牌黄色，不建立第二套设计系统。
- 全屏画面不增加永久遮罩；只有控件背后使用局部渐变保证文字可读。
- 参数面板使用高不透明浅色背景和轻微模糊，保证真机户外环境仍可读。
- 所有可点击区域不小于 44dp；滑块和数字输入必须同时提供。
- 图层条只能点击选择，不支持长按、拖动或交换。
- 控件隐藏后只保留低干扰唤回入口，画面仍保持真实比例和传感器响应。
- 保存、错误和版本冲突不能只用颜色表达，必须同时显示文字或图标。
