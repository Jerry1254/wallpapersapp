# ARC-003 4D 分层视差壁纸原理

## 当前统一模型

4D 壁纸由 2～12 张等尺寸图片组成，`01` 是最前景，最后一张是完整不透明背景。图层顺序只决定遮挡，运动参数由 Web 模拟器配置，Android 原样执行；API 只保存、交付并检查稳定的文件结构。

每层共用一个运动方向：

- `follow`：跟随手机倾斜方向。
- `reverse`：向手机倾斜的反方向运动。
- `fixed`：不参与动态运动，但初始位置修正仍生效。

水平和垂直分别配置：

- `motion.maxAngleX`、`motion.maxAngleY`：达到对应轴满幅位移的倾斜角，范围均为 `1°～75°`，默认 `75°`，全图层共用。
- `offsetXPercent`：满幅水平倾斜时相对屏幕宽度的运动比例，非负且无产品上限。
- `offsetYPercent`：满幅垂直倾斜时相对屏幕高度的运动比例，非负且无产品上限。
- `initialOffsetXPercent`：中立姿态的水平位置修正，负数向左、正数向右。
- `initialOffsetYPercent`：中立姿态的垂直位置修正，负数向上、正数向下。

`100` 表示一个完整屏幕轴长。参数可以大于 `100`，允许把图层移出屏幕。传感器从中立位置的第一个非零角度开始线性响应，没有启动死区。

## 计算规则

```text
progressX = clamp(horizontalAngle / maxAngleX, -1, 1)
progressY = clamp(verticalAngle / maxAngleY, -1, 1)
sign = follow ? 1 : reverse ? -1 : 0

xPx = initialOffsetXPercent / 100 * screenWidth
    - sign * progressX * offsetXPercent / 100 * screenWidth

yPx = initialOffsetYPercent / 100 * screenHeight
    + sign * progressY * offsetYPercent / 100 * screenHeight
```

图层在中立姿态时只应用初始位置。水平与垂直强度互不影响，例如水平 `100`、垂直 `50` 表示满幅时分别移动一屏宽和半屏高。

背景为了避免运动时露出空白，运行时根据“初始位置绝对值 + 对应轴最大动态位移”计算所需保护缩放并居中裁切。该处理只影响显示矩阵，不修改源图片，也不降低分辨率。前景允许移出屏幕，不强制裁切其位移。

## 配置示例

```json
{
  "formatVersion": 2,
  "canvas": { "width": 2048, "height": 2048 },
  "motion": { "maxAngleX": 75, "maxAngleY": 75 },
  "layers": [
    { "index": 1, "offsetXPercent": 15, "offsetYPercent": 10, "initialOffsetXPercent": 0, "initialOffsetYPercent": -2, "direction": "follow", "scale": 1.18, "opacity": 1, "blendMode": "normal" },
    { "index": 2, "offsetXPercent": 5, "offsetYPercent": 3, "initialOffsetXPercent": 4, "initialOffsetYPercent": 0, "direction": "follow", "scale": 1.18, "opacity": 0.25, "blendMode": "screen" },
    { "index": 3, "offsetXPercent": 3, "offsetYPercent": 2, "initialOffsetXPercent": 0, "initialOffsetYPercent": 0, "direction": "reverse", "scale": 1, "opacity": 1, "blendMode": "normal" }
  ]
}
```

完整字段约束见 [`parallax-source-v2.schema.json`](../../packages/wallpaper-format/parallax-source-v2.schema.json)。当前产品尚未上线，正式 App、正式导出和正式发布只接受这一版 v2 字段集合，不保留旧运行格式。Web 模拟器为了找回测试素材，可在导入阶段把旧 `formatVersion=1` 的 `depth/strength` 工程一次性换算为当前 v2；转换后的项目必须检查效果并重新保存，Android 不直接运行旧配置。

## 分辨率与资源边界

正式 Android 以源尺寸、ARGB_8888、`inSampleSize=1` 解码每层，不静默降采样。配置画布和每张图片尺寸必须一致，宽高均为 `512～4096`，图层数为 `2～12`。背景必须完全不透明；前景必须保留透明通道。
