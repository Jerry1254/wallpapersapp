# API-006 壁纸设置教程接口

**状态：** 已实现

**版本：** API V1.4.0

**日期：** 2026-09-15

**调用方：** 管理后台、Android App；HarmonyOS 与 iOS 后续复用。已完成的 H5 原型保留现有接入，但自 2026-09-15 起不再维护

## 1. 目标与固定教程

教程采用五个固定槽位。管理员不能新增或删除类型，只能上传新 MP4、启用或停用并调整显示顺序。客户端从公开 API 读取，不把正式教程视频打进安装包。

| key | 前台标题 | platform | wallpaperKind | 详情匹配 |
|---|---|---|---|---|
| `ANDROID_PARALLAX_4D` | 4D动态壁纸教程 | `ANDROID` | `PARALLAX_4D` | Android 4D 壁纸 |
| `ANDROID_DYNAMIC` | 动态壁纸教程 | `ANDROID` | `DYNAMIC` | Android MP4 动态壁纸 |
| `STATIC` | 静态壁纸教程 | `UNIVERSAL` | `STATIC` | 全平台静态壁纸 |
| `HARMONYOS_DYNAMIC` | 华为动态壁纸教程 | `HARMONYOS` | `DYNAMIC` | 华为/HarmonyOS 动态壁纸 |
| `IOS_DYNAMIC` | 苹果动态壁纸教程 | `IOS` | `DYNAMIC` | iOS 动态壁纸 |

“我的 → 壁纸设置教程”按 `sortOrder ASC, key ASC` 展示所有已启用且视频资源为 `READY` 的教程。壁纸详情根据当前客户端平台和壁纸 `kind` 选择唯一 `key`；找不到时提示“对应的设置教程暂未发布”。

## 2. 管理端上传资源

复用现有资源上传端点，给 `AssetPurpose` 增加 `TUTORIAL_VIDEO`：

```http
POST /api/v1/admin/assets
Content-Type: multipart/form-data
X-CSRF-Token: {csrfToken}
X-Request-Id: {uuid}

purpose=TUTORIAL_VIDEO
file=@android-dynamic-tutorial.mp4
```

服务端要求：

- 文件真实类型必须为 `video/mp4`，扩展名不能代替内容探测。
- 限制 200 MB、15 分钟以内，并从 MP4 `moov/mvhd` 读取时长；结构不完整或超限时拒绝上传。
- 资源校验为 `READY` 后才允许绑定教程。
- 建议使用 H.264 视频和 AAC 音频以覆盖 Android、iOS 与主流浏览器。
- 文件继续通过现有 `FileStorage` Port 保存，数据库不得记录绝对路径。

成功响应沿用现有 `AdminAsset`，客户端保存其中的字符串 `id`。

## 3. 管理端读取五个槽位

```http
GET /api/v1/admin/wallpaper-tutorials
Cookie: admin_session=...
```

成功响应 `200`：

```json
{
  "items": [
    {
      "key": "ANDROID_PARALLAX_4D",
      "title": "4D动态壁纸教程",
      "platform": "ANDROID",
      "wallpaperKind": "PARALLAX_4D",
      "enabled": true,
      "sortOrder": 10,
      "video": {
        "id": "901",
        "originalFilename": "android-4d-tutorial.mp4",
        "mimeType": "video/mp4",
        "sizeBytes": 23891234,
        "durationMs": 86200,
        "validationStatus": "READY",
        "previewUrl": "/api/v1/admin/assets/901/content"
      },
      "updatedAt": "2026-09-15T11:30:00+08:00",
      "version": 3
    }
  ]
}
```

接口必须始终返回五个固定槽位。尚未配置的槽位返回 `video: null`、`enabled: false`、`version: 0`，便于管理后台第一次保存时使用 `If-Match: "0"`。

## 4. 管理端上传或更新教程

```http
PUT /api/v1/admin/wallpaper-tutorials/{tutorialKey}
Content-Type: application/json
Cookie: admin_session=...
X-CSRF-Token: {csrfToken}
X-Request-Id: {uuid}
If-Match: "3"

{
  "videoAssetId": "902",
  "enabled": true,
  "sortOrder": 10
}
```

成功返回 `200`、完整管理模型和新的 `ETag`。第一次配置使用 `If-Match: "0"`。`title`、`platform` 和 `wallpaperKind` 由固定 `tutorialKey` 决定，写请求不允许修改，避免客户端匹配漂移。

校验规则：

- `tutorialKey` 必须属于固定五项。
- `videoAssetId` 必须存在、用途为 `TUTORIAL_VIDEO`、状态为 `READY`、MIME 为 `video/mp4`。
- `enabled=true` 时必须有有效视频。
- `sortOrder` 为 `0..9999`。
- 更新使用乐观锁；版本不一致返回 `412 VERSION_CONFLICT`。
- 保存成功写管理审计，至少包含教程 key、旧/新资源 ID、启用状态和管理员 ID。

不提供删除接口。需要撤下教程时提交 `enabled=false`；被新版本替换的资源按现有资源引用规则回收。

## 5. 前台读取教程

```http
GET /api/v1/public/wallpaper-tutorials
```

无需登录。只返回已启用且视频资源为 `READY` 的项目：

```json
{
  "items": [
    {
      "key": "ANDROID_DYNAMIC",
      "title": "动态壁纸教程",
      "platform": "ANDROID",
      "wallpaperKind": "DYNAMIC",
      "video": {
        "contentUrl": "/api/v1/public/wallpaper-tutorials/ANDROID_DYNAMIC/video?v=4",
        "mimeType": "video/mp4",
        "durationMs": 73400,
        "sizeBytes": 19480211
      },
      "sortOrder": 20,
      "updatedAt": "2026-09-15T12:00:00+08:00",
      "version": 4
    }
  ]
}
```

前台必须直接使用服务端返回的 `contentUrl`，不得自行拼接资源 ID。服务端可把该地址切换到对象存储或 CDN，响应模型保持不变。

## 6. 视频流读取

```http
GET /api/v1/public/wallpaper-tutorials/{tutorialKey}/video?v={version}
Range: bytes=0-
```

要求：

- 支持标准 `Range` 请求，返回 `206`、`Content-Range`、`Accept-Ranges: bytes` 和准确 `Content-Length`；无 Range 时可返回 `200`。
- `Content-Type: video/mp4`，支持 `HEAD`；HEAD 忽略 Range，返回完整内容长度且无响应体。
- `If-Range` 匹配当前强 ETag 时返回分段；不匹配时返回完整内容。越界范围返回 `416` 和 `Content-Range: bytes */{size}`。
- 未启用、未配置或资源非 `READY` 返回 `404 TUTORIAL_NOT_FOUND`。
- `v` 用于缓存换版；当前版本 URL 允许公开长缓存；缺失或与当前版本不一致时返回当前内容与 `Cache-Control: no-cache`，不把新内容按旧版本长期缓存。
- 视频为公开教程内容，不要求设备权益或下载票据。

## 7. 错误响应

继续使用现有 `ErrorEnvelope`。本功能增加以下稳定错误码：

| HTTP | code | 场景 |
|---|---|---|
| 404 | `TUTORIAL_NOT_FOUND` | key 不存在、教程未启用或公开视频不可用 |
| 409 | `TUTORIAL_ASSET_IN_USE` | 服务端资源清理时仍被教程引用 |
| 412 | `VERSION_CONFLICT` | 管理端保存使用了旧版本 |
| 422 | `TUTORIAL_VIDEO_REQUIRED` | 启用时没有视频 |
| 422 | `ASSET_NOT_READY` | 上传资源尚未校验完成 |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | 不是有效 MP4 |

其他身份、CSRF、限流和内部错误沿用 API-001。

## 8. 数据与实现建议

MySQL 增加单表 `wallpaper_setting_tutorial`，以 `tutorial_key` 为主键，保存 `video_asset_id`、`enabled`、`sort_order`、`lock_version`、创建及更新时间。五个 key 通过迁移预置；标题、平台和壁纸类型可由服务端常量映射，避免产生第二份可编辑事实。

当前公开列表直接读 MySQL，视频资源使用带版本号的 URL 长缓存。后续若增加列表缓存，更新教程后必须主动失效。Redis 只保存可丢失缓存，不作为教程配置事实来源。

## 9. 客户端已约定的行为

- 管理后台新增“设置教程”页面，读取五个槽位，上传 MP4 后调用更新接口。
- H5 与 App 的教程目录从公开列表读取，点击后在播放器弹层中播放并可关闭。
- H5 详情根据浏览器平台选择 Android、HarmonyOS 或 iOS 动态教程；无法识别的平台按 Android 入口展示，静态壁纸始终使用通用教程。
- Android 详情映射：`PARALLAX_4D → ANDROID_PARALLAX_4D`、`DYNAMIC → ANDROID_DYNAMIC`、`STATIC → STATIC`。
- HarmonyOS 与 iOS 接入时分别使用 `HARMONYOS_DYNAMIC`、`IOS_DYNAMIC`，静态继续使用 `STATIC`。
- 请求失败展示重试状态；缺少对应教程只提示未发布，不回退到错误类型的视频。
- H5 原型已经完成并冻结；其现有教程接入保留为历史基线，后续接口演进与回归不再以 H5 为维护目标。
