# 04-接口设计

本目录用于保存客户端、内容管理后台与接口服务之间的 API 契约。

当前有效接口基线：

- [API-001 OpenAPI V1 契约说明](API-001-OpenAPI-V1契约说明.md)：接口边界、认证、分页、错误码、幂等、乐观锁与下载模式。
- [API-002 管理身份与内容 API 实现说明](API-002-管理身份与内容API实现说明.md)：管理员会话、资源、分类、壁纸、版本、发布和审计实现边界。
- [API-003 兑换、设备与权益 API 实现说明](API-003-兑换设备权益API实现说明.md)：设备会话与签名、一次性交付、幂等兑换、权益和管理查询实现边界。
- [OpenAPI V1 机器契约](../../contracts/openapi/openapi.yaml)：H5、App、管理后台与 Java API 的唯一机器可读契约。

接口使用稳定字符串 ID 和资源摘要，不通过公开接口传输未压缩图层、存储键、绝对路径、完整兑换码或永久正式资源地址。
