# 04-接口设计

本目录用于保存客户端、内容管理后台与接口服务之间的 API 契约。

当前有效接口基线：

- [API-001 OpenAPI V1 契约说明](API-001-OpenAPI-V1契约说明.md)：接口边界、认证、分页、错误码、幂等、乐观锁与下载模式。
- [API-002 管理身份与内容 API 实现说明](API-002-管理身份与内容API实现说明.md)：管理员会话、资源、分类、壁纸、版本、发布和审计实现边界。
- [API-003 兑换、设备与权益 API 实现说明](API-003-兑换设备权益API实现说明.md)：设备会话与签名、一次性交付、幂等兑换、权益和管理查询实现边界。
- [API-004 公开目录 API 与 H5 联调说明](API-004-公开目录API与H5联调说明.md)：公开可见性、分类/搜索/分页、封面边界和 H5 真实目录接入。
- [API-005 H5 设备、兑换与权益联调说明](API-005-H5设备兑换与权益联调说明.md)：测试设备签名、待确认兑换恢复、真实权益和下载占位。
- [API-006 壁纸设置教程接口](API-006-壁纸设置教程接口.md)：五类固定教程的后台上传更新、公开读取、Range/HEAD 视频流和客户端匹配规则；API V1.4.0 已实现。
- [API-007 4D 固定资源包导入接口](API-007-4D固定资源包导入接口.md)：固定 ZIP 和 JSON、源包解析、资源版本生成及兼容规则；新增接口待 API 团队实现。
- [API-008 4D 配置透传与管理后台改造方案](API-008-4D配置透传与管理后台改造方案.md)：4D 原始配置、稳定结构校验、正式包交付和后台职责边界。
- [API-009 4D 独立轴配置 Java 交接说明](API-009-4D独立轴配置Java交接说明.md)：本次算法字段变化、Java 是否需要修改的判断表和自查验收项。
- [API-010 1.0 原资源详情预览 Java 交接说明](API-010-1.0原资源详情预览Java交接说明.md)：静态原图、原始 MP4 和原始 4D 分层资源的 APP_PREVIEW 制作规则、既有预览包重建与验收要求。
- [API-011 4D 真机调试配置保存实现说明](API-011-4D真机调试配置保存实现说明.md)：Lab App 整体保存、管理员认证、版本冲突与不可变资源版本规则。
- [API-012 免费壁纸获取方式接口交接说明](API-012-免费壁纸获取方式接口交接说明.md)：作品级获取方式、公开筛选、免费正式下载授权、兑换保护和缓存失效规则。
- [API-013 非 4D 动态/静态双形式交付与管理后台对接说明](API-013-非4D动态静态双形式交付与管理后台对接说明.md)：单作品权益下的动态/静态选择、静态原图复用、资源变体、票据和发布校验规则。
- [OpenAPI V1 机器契约](../../contracts/openapi/openapi.yaml)：H5、App、管理后台与 Java API 的唯一机器可读契约。

接口使用稳定字符串 ID 和资源摘要，不通过公开接口传输未压缩图层、存储键、绝对路径、完整兑换码或永久正式资源地址。
