## 迁移范围

Flyway V1 创建以下业务表：`admin_account`、`asset`、`category`、`wallpaper`、`wallpaper_variant`、`resource_version`、`resource_binding`、`anonymous_device`、`device_credential`、`code_batch`、`redemption_code`、`device_entitlement`、`redemption_request`、`redemption_event`、`download_event` 和 `audit_event`。

迁移没有写入管理员密码、兑换码或演示数据。MySQL 是业务事实源；Redis 重启不会删除 schema 或 MySQL 验收标记。

## 实施中发现并修正的问题

- Maven 在中文工作区下继承 US-ASCII 时，测试 fork 路径会失真。仓库已通过 `.mvn/jvm.config` 固定 UTF-8。
- Testcontainers 不读取 Docker CLI context。Maven Wrapper 现在在未显式提供 `DOCKER_HOST` 时读取当前 context，并为 Colima/Docker Desktop 设置容器内 socket 路径。
- MySQL 8.4 不允许 CHECK 引用自增列，因此分类自引用防护保留在后续 catalog 服务事务中；数据库继续通过层级形状、外键和同父唯一约束保护结构。
- `wallpaper_variant.capability_requirements` 已补入 DB-001 与 Flyway，作为受控字符串数组保存；业务查询不依赖 JSON 内字段。
