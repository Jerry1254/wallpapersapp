## 3. 异常与额外断言

- 同设备同幂等键同 body 重放返回原 RedemptionResult，GET 原 key 确认结果完全一致；新键重复兑换 ALREADY_OWNED、quotaDelta=0；原键改码返回 409 IDEMPOTENCY_KEY_REUSED。
- 获益设备重复请求下载描述两次均为 H5_PLACEHOLDER；拒绝设备无权益和无下载能力，额度不超发。
- 下线后公开详情和封面 404，旧权益仍可查询、下载占位仍可请求；下线前、下线后、重启后三次事实相等。重新发布同一不可变版本成功。
- WP-P10 已验证暂停 API 导致真实请求超时、刷新后只确认原 key，不重新扣额度；该代码在本轮 19 个 H5 测试中继续覆盖，无新增 Java 改动。
- 后台 4D 配置曾被标为选填，与资源版本规则冲突。现已改为必填，并在 Repository 的任何上传/网络请求前拒绝缺失配置；新增测试验证没有部分写入。背景 PNG 与后端接受类型对齐；过期 WP-P08 文案和 iOS JPEG 提示同步修正，H5 无效码提示移除不存在的“停用”状态。
