## 2. 浏览器验收

使用 Codex 浏览器验证本地 H5：

1. API 未就绪时首页展示可重试错误；API 恢复后点击重新加载，读取真实分类。
2. 最近上新和静态视图读取后台此前发布的“联调晨雾”，卡片和分类图标均来自 /api/v1/public/assets 受控地址。
3. 进入“联调风景”，二级“联调静态”筛选结果正确。
4. 输入中文“晨雾”搜索，返回 1 张真实壁纸；打开详情，封面、类型、分类和版权说明与服务端一致。
5. 不存在的关键词返回空结果；不存在的壁纸 ID 显示“内容不存在或已经下线”，可返回首页或重试。
6. 当前没有推荐和 4D 内容时对应视图展示空状态，静态内容没有混入 4D 结果。
7. 1280 像素桌面和 390×844 移动端视觉检查通过；document.documentElement.scrollWidth 等于视口宽度，图片完整加载。测试结束后已恢复浏览器尺寸。
