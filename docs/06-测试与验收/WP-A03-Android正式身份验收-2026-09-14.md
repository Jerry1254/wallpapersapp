日期 2026-09-14。状态以 PM-002 为准。前置 A02 提交 78cb4c0 已推送且 CI 34795641350 通过；真机仍缺。

## 已实现

- Kotlin 独立插件在后台线程生成 AndroidKeyStore RSA 2048 安装签名密钥；私钥不导出，注册 proof 和敏感请求签名使用 SHA256withRSA。Dart 不保存私钥或 H5 secret。
- API PLATFORM_PUBLIC_KEY Provider 校验 scope 允许值、公钥规格、时间、nonce、注册持钥签名；同公钥新证明恢复原 ACTIVE 凭据，撤销/禁用拒绝。挑战和签名请求防重放，nonce 覆盖完整 2×时钟偏差窗口。
- Flutter 单次并发会话创建/续期，401 最多自动续期一次，准确 body 字节/规范路径/时间和随机 nonce 签名；Token 仅内存，原生只保存凭据编号。我的页面可连接身份并真实访问权益 API。
- 身份只证明安装密钥持有，不证明硬件级别、APK 来源或物理设备唯一性。清数据/卸载丢钥不自动恢复旧权益，详细边界见 SEC-002。
