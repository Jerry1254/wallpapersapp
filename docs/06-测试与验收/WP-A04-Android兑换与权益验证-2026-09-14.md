日期：2026-09-14。状态：待验收。实现及真机兑换/未知结果恢复已验证；前序安装身份边界与整体门禁继续在 A10 收口。以下早期检查保留当时条件。

## 实现范围

Android 使用 A03 RSA 会话访问正式 `/device/redemptions`、原 key 结果查询和 `/device/me/entitlements`。兑换弹层说明额度和安装身份边界，隐藏输入，禁止重复点击；详情仍由资源变体、原生预览和系统设置能力共同限制入口。当前原生能力未接入，默认入口禁用，不为演示提前扣额度。

一个应用实例共用兑换协调器。提交前同步持久化 `{key, wallpaperId, bodyHash}`，保存到应用私有 SharedPreferences，与安装身份一起清理，不保存明文兑换码、请求正文或 Bearer。响应丢失、5xx、409、未知结果保留原意图；后续查询原 key，重新输入原码只重发相同 key、作品和摘要。不同意图不得覆盖。首次请求明确的 400/401/403/404/429 可清除未提交意图；已有不确定请求遭遇这些错误仍保留，不能据此否定之前已提交的事务。只有匹配 key 的已知最终结果才清除记录。设备凭据或持久化损坏不静默生成新意图。

“我的壁纸”从真实权益接口读取和分页，去重、加载/刷新、错误和空态可见；获得权益和本地安装状态分别显示。可主动确认上次兑换结果。当前本地安装未实现，明确显示尚未安装。

服务端在 Android 新授权扣额度前校验已发布 Android/UNIVERSAL 的 STATIC_IMAGE、VIDEO、LAYER_PARALLAX 变体；不满足返回既有 WALLPAPER_UNAVAILABLE / quotaDelta=0。已拥有仍返回 ALREADY_OWNED，不额外扣减。H5 流程保持原契约。未修改 Flyway V1、数据库结构或冻结契约文件。
