# WP-A05 安全资源交付实施记录

日期：2026-09-14。状态：待验收。服务端实现、相关测试、文档和 1.2.0 格式/契约冻结完成；Android 真机安全安装与完整交付链由 A06 验收。

## 实现结果

format 2 为签名 ZIP 的 AES-256-GCM 密文，AAD 绑定作品、变体、版本与类型。逐文件摘要与原字节 manifest RSA 签名覆盖 payload；每版本随机内容密钥由服务端 master key 保护存储，向安装独立解密公钥使用 OAEP-SHA256-MGF1-SHA1 包装。原 A03 签名密钥、credentialKeyId 和权益身份保持。

`PUT /device/encryption-key` 使用既有 Android RSA 签名会话绑定独立 RSA 公钥，同值幂等、异值拒绝。Android 插件增加 DECRYPT/OAEP Keystore 密钥，Dart 会话管理器合并并发绑定并检查返回指纹；尚未实现实际解密安装。

`POST /admin/resource-versions/{id}/secure-package` 从 FileStorage 读取已绑定资源，通过摘要、FFprobe 探测、FFmpeg 全量解码和分层严格配置检查，制作不可变包。PNG 静态、H.264 无音频视频、透明 PNG 分层均验证；伪 MP4、越界/畸形分层配置拒绝。已有包重试不变；READY 制作失败或事务回滚清理存储对象及记录，已发布无包的旧版本需新增版本。

后台页面发布 Android/UNIVERSAL 兼容 READY 版本前自动制作，失败停止发布。旧公开版本可能无安全包；Android 新兑换要求可用安全版本，不满足时不授予权益或扣额度。已有权益保留，下载再次检查兼容性。H5 保留 H5_PLACEHOLDER。

90 秒 Redis 票据绑定设备、签名凭据、解密公钥、资源版本与平台。签发、开始读取及异步流开始均重查 MySQL 权益/状态，已撤销/下架/退役或失效票据拒绝。包通过 Authorization 受控流式读取，长度/Digest/no-store 明确；响应不暴露 StorageKey、绝对路径或明文内容密钥。创建 30 次/分钟、读取 12 次/分钟，每进程最多 4 个下载流、1 个制作任务。已开始的流可以完成，已下载内容不能远程收回。

V2 仅新增 device_encryption_key、secure_resource_package 两表。V1 字节不变；隔离升级测试先 V1 写入安装/凭据哨兵，再迁移 V2，逐字确认身份字段保留。它不单独证明所有历史业务数据升级路径。

## 验证与冻结

- 最终 `./mvnw verify` 退出 0：27 单元测试、9 MySQL/Redis 集成测试，失败/错误/跳过均 0。真实三类媒体经过管理 API 上传→制作→发布→签名 Android 兑换→票据→HTTP 读取→OAEP/GCM 解密、摘要及签名验证；错误平台、无权益、最低系统版本、撤销、下架、退役、限流和票据失效均拒绝。票据失效通过强制 Redis 到期验证，不声称等待了完整 90 秒。日志 `.runtime/android-evidence/a05-final-api-verify.log`。
- 编码器单元测试验证三类结构、原字节签名/逐文件摘要、篡改、错 AAD 和错解密密钥失败、随机密钥/密文不复用、错误/缺失/重复角色拒绝。真实媒体证据来自集成测试，不来自结构测试字节。
- 后台 13 测试、类型检查及构建通过，包含制作失败停止发布。H5 19 测试及类型检查通过，另跑构建。Flutter analyze、21 测试通过，1 显式本地 API 用例跳过；localDebug 和 localRelease 构建通过，release 签名及三环境 manifest 检查通过。
- OpenAPI lint/专项覆盖通过：49 操作、74 Schema、113 个直接 Java 错误码字面量。1.2.0 冻结 14 个文件，历史 baseline-v1.1.0.json 与上次接受提交相同；只修改明确审阅的 6 个旧冻结文件，V1、Token 和 SEC-002 不变，新增 V2、SEC-003 和两个 Schema。
