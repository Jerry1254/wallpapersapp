## 实现

Flutter 使用设备会话签署真实下载票据请求，Android osVersion 使用系统发行版本（如 15），不混用 SDK/API 编号（如 35）。检查作品、资源类型、绑定解密公钥摘要和固定读取路径。票据仅在内存中通过 Authorization 使用，下载 URL 只解析到应用配置的同一源，不跟随重定向，不保存会话、票据或包装内容密钥。详情页与“我的”可进入下载，展示准备/进度/校验/安装/失败及本地资源状态。

Android 插件通过独立线程读取资源，检查 HTTP 类型/长度，限制超时与累计字节，进度由 EventChannel 回传，取消直接设置标记并断开连接。中断后重新申请票据并从头下载，不拼接未经验证的旧片段。下载和验证期间不会记为已下载，提交成功才返回已安装 ID。

信任根从 local/prod 各自构建配置编入 Android string 资源；不接受包或响应提供的公钥，空配置拒绝安装。独立 Keystore DECRYPT 密钥在原生内部 OAEP 解包内容密钥，私钥/明文内容密钥及资源文件路径不跨通道。密文 SHA-256/长度→格式头/GCM AAD/tag→ZIP 明文摘要/长度→manifest 原字节签名/摘要→严格 JSON 和全部文件长度/摘要/CRC→实际媒体及分层配置校验完成后才安装。

安全解包在新建私有 staging 内执行，先验证 ZIP 中央目录与本地头的一致性，拒绝 ZIP64、目录、链接、重复/越界/未知文件、加密 ZIP、外部前缀、尾随数据及内容区重叠。仅允许固定 payload 文件名，创建普通文件而不遵从 ZIP 链接属性。清单角色、ordinal、类型、总量、文件集合及分层配置均对应冻结 format 2；重复 JSON 键、尾随输入、错误 UTF-8/数值/层数拒绝。

已有目录只有与刚验证完成的 manifest、签名及全部 payload 长度/摘要一致时才复用；缓存损坏拒绝返回安装成功。版本目录保持不可变，验证完成后通过原子目录移动和原子 current 指针切换提交。首次失败清理暂存，新版验证或切换失败保留原版；同变体降级与同版本内容变更拒绝。启动清理中断留下的 .stage/.part/.pointer，只清理未提交状态。清理资源保留 active-home/active-lock 指定的所有使用版本，正在下载时拒绝清缓存。系统实际使用记录由 A07/A08 的原生设置流程写入。

下载前预留三倍密文大小及 16 MiB 磁盘空间，GCM 与图片解码前检查可用堆预算；不足时返回明确提示并保留原版，OOM 也不提交未验证版本。最大格式尺寸不代表所有手机均有足够内存，真实内存/磁盘不足及性能边界需 A10 设备矩阵验证。
