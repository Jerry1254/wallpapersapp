## 迁移范围与来源

迁移来源为仓库 PoC `app/src/main/java/com/livewallpaper/parallaxdemo` 的 `TiltSensor`、`ParallaxScene`、`ParallaxPreviewView` 和 `ParallaxWallpaperService`。保留旋转向量优先级、首帧姿态校准、角度归一化、分层深度和居中覆盖逻辑。正式实现改用签名校验后的私有安装包，读取配置中的角度、平滑、强度、缩放、透明度和混合模式；使用独立渲染线程、可见性门控、解码预算和资源引用保护。

## 验收与性能方案（先固定条件）

- 功能：App 独立预览、真机实际倾斜、旋转方向、最大位移不露黑边、无传感器静态降级、系统实际选择目标、取消保留原资源、缓存保护、隐藏/关闭屏幕释放、重新可见及进程重建恢复。
- 单元验证：角度跨 ±π、四种屏幕方向、位移边界、不同平滑系数和时间间隔、配置非法值及总解码预算；同时回归 A07 设置结果与安全包校验。
- A10 性能复测素材：1080×2400，两层（背景与透明前景），正常混合，30 fps 上限；可见预热 5 分钟后 30 分钟，隐藏 10 分钟。可见首帧 ≤3 秒、隐藏后停止绘制/注销传感器/释放图片 ≤1 秒；预热后 PSS 增长 ≤20 MiB，无 ANR/崩溃。记录实际帧率、CPU、电量和温度及静态基线差异，不预先宣称功耗合格。
- 自动验证只证明渲染、生命周期和资源保护；真实倾斜的视觉方向需物理操作确认。小尺寸夹具不计为上述长时性能结果。

## 失败、修复与迁移差异

首次重跑夹具时，相同版本的清单因 Java Map 字段迭代顺序变化产生不同摘要，客户端正确拒绝覆盖。正式发布本身按资源版本保存不可变包并幂等复用，无需因此放宽安全校验。夹具现按来源摘要复用原包，来源变化才递增版本；连续准备三类包的加密内容、描述和内容密钥不变检查已通过。

与 PoC 相比，正式版本采用每个查看器/Engine 独立线程与租约，异步复验私有资源后才解码；可见性代次阻断旧加载和旧帧。角度、平滑、强度、层顺序、透明度和 normal/screen/add 来自严格配置；位移限制在实际覆盖余量内，方向随屏幕旋转重新校准；按时间间隔调整平滑，最多 30 fps，无传感器时仅绘制静态帧。两类动态服务各自保留资源并兼容旧视频指针，取消/失败不覆盖提交版本。

补充联调准备：已创建独立本地 Android API 环境（8083，MySQL 3311、Redis 6391，独立数据/凭据/存储），当前 1.2.0 API 的 V1/V2 空库迁移及完整 db/redis 健康检查通过；手机通过 ADB reverse 访问 8083 的公开分类 HTTP 200。当前目录为空，不将连通性当作完整业务下载验收。
