## 实施边界

未获得时可使用独立预览资源进入 App 内 120 秒试用，提前退出或到期后清理临时状态；不写入权益、不扣兑换额度、不设置系统壁纸、不输出完整付费资源。已获得时继续使用正式下载与预览。

已实现与正式包可明确区分的签名预览包，携带独立 purpose/format，使用独立票据命名空间、下载路径和 Android 临时库。正式安全安装/系统壁纸入口拒绝预览包；预览入口拒绝正式包冒充试用。服务端生成降低规格且带试用标记的素材，保留三类实际效果，禁止以封面或原始付费包代替。服务器源数据仍来自 MySQL 和资源 Adapter，Redis 只保存短时票据和限流状态。

计时由 Android 单调时钟执行，从实际预览开始计 120 秒；进入后台停止画面、播放器与传感器，但计时继续。进程恢复沿用原截止时间，检测重启后放弃旧试用；新开始清理未完成的旧临时状态。结束或到期释放播放器/图片/租约并删除临时试用资源，不将临时库注册为正式安装版本。

OpenAPI 增加独立预览交付契约并升级当前版本；保留 1.2.0 历史冻结输入，不改写 Flyway V1/V2，新增迁移。契约/API 与用途格式回归通过后冻结 1.3.0 并提交可独立审核实现；A09 总工作包完成状态须等待实际真机验收，不以组件提交当作已完成。

## 当前实施进度

SecurePackageCodec 已增加 encodePreview：magic 为 QJPV0001，签名清单 formatVersion=3、purpose=APP_PREVIEW，加密 AAD 前缀为 QJ-PREVIEW-V1；正式 format 2 保持原标记、字段与 AAD。受限素材生成器使用真实图像解码、FFmpeg WebP/静音 H.264 派生，重复 QJ 标记与 1280 规格限制；4D 保留前景透明与姿态参数。V3 保存独立资源元数据，试用 ticket/read 使用独立票据和路径，签名设备路由覆盖新敏感 POST。详细协议见 SEC-004。

Android 增加独立临时库、受限包安装/持久化校验、随机 trialId 与私有 NativeTrialActivity，真实图片/视频/4D 共用既有渲染能力；正式入口默认只接受 format 2。首帧后固定 elapsedRealtime 截止，BOOT_COUNT 和原截止写入本机；后台、失焦、锁屏停止并释放画面/传感器，恢复不延期，结束清除状态并等待租约释放后删文件。删除失败保留待下一次恢复/准备重试，不把清理动作当作即时完成保证。没有缩短时长的原生调试开关。

Flutter 先查询当前安装权益，未获得时展示受限试用，已获得时展示正式下载/预览；兑换结束重新读取权益。试用获取描述、取消准备、安装完成取消、打开失败和结束均处理临时清理。启动恢复沿用原 trialId/截止。切换空本地 API 遇到确定 404 CREDENTIAL_NOT_FOUND 时以同一 Keystore 公钥重新证明身份；撤销、禁用和网络不确定不触发重新注册，私钥和原生正式资源保留。
