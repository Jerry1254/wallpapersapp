# WP-A10 Android 全链路真机验收

状态：进行中。本文随实际验收更新，计划和未测项不记为通过。

## 环境与机型

只使用本工作树的隔离本地 API 8083、MySQL 3311、Redis 6391 和生成素材；不部署生产，不同步其他环境业务数据。手机通过已授权无线 ADB reverse 访问电脑 API。目标设备为 Redmi M2012K11AC / alioth，Android 13，1080×2400、arm64；其他机型尚未验收。

现有 `.local` App 保留数据和 Keystore。新增独立 `.internal` 候选内测安装标识及独立测试签名，用于新装、升级、卸载后的身份恢复边界测试；生产包仍独立且没有生产签名。候选内测只连接 HTTPS loopback API，通过 8443→8083 本机代理与 ADB reverse 访问，不要求手机配置数据库或手动部署 API。

仅 internal flavor 信任构建时配置的公共 loopback TLS 证书：Android 原生连接采用仅覆盖 localhost/127.0.0.1 的 network security config；Dart 添加同一公共证书，保留证书链、有效期与主机名校验，没有 accept-all 回调。做法依据 [Android 官方网络安全配置](https://developer.android.com/privacy-and-security/security-config) 和 [Dart SecurityContext 文档](https://api.dart.dev/dart-io/SecurityContext/setTrustedCertificatesBytes.html)。证书私钥与签名 Keystore 只存忽略的运行时目录；生产 flavor 不添加内测信任。
