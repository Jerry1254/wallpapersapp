- TUTORIAL_VIDEO 上传限制 200 MiB（200 × 1024 × 1024 字节）、15 分钟；检查 MP4 结构并读取时长，FileStorage 隔离存储路径。
- 公开目录只返回启用且资源就绪的教程；提供 MP4 GET/HEAD、单段 Range、ETag。停用后新的目录/源站视频请求不可读取；已缓存或已下载的公开视频不能远程收回。
- 后台提供上传、替换、启停、排序、刷新与视频预览。
- OpenAPI 1.4.0：56 个操作、83 个 Schema、128 个直接 Java 错误码字面量覆盖、19 个冻结文件。1.3.1 历史快照与原 HEAD 一致。

## 2. 本次收口修正

1. 旧版本或无版本 URL 返回当前内容时使用 `Cache-Control: no-cache`；只有当前版本 URL 使用一年公开长缓存，避免新视频长期缓存在旧版本地址。
2. HEAD 忽略 Range 并返回完整长度；If-Range 不匹配当前强 ETag 时返回完整内容；416 返回 `Content-Range: bytes */{size}`。真实 HTTP 集成剧本新增对应断言。
3. 交接快照中的 OpenAPI 摘要已经落后于实际文件。本次审阅 1.3.1→1.4.0 增量及上述 HTTP 语义后，仅更新未发布 1.4.0 中 OpenAPI/API-006 的摘要，未自动重写其他摘要或历史快照。
4. 第一次本轮回归的隔离 MySQL 未在默认 120 秒内启动；停止该轮测试，将迁移测试等待设为现有基础设施测试使用的 300 秒后重跑。未停止其他项目容器。随后核对历史 A05 环境说明，发现默认 PATH 缺少媒体工具，停止不完整配置的回归，显式传入现有 `.runtime/media-tools/ffmpeg` 与 `ffprobe` 及 UTF-8 locale 后执行最终整套回归。
