**日期：** 2026-09-15

**结论：** 管理后台/API/数据库实现和本地联调完成；Android 多层倾斜短验收待设备连接。WP-UI05 保持待验收，不把后台验证计为真机通过。

## 本次交付

- `POST /admin/parallax-packages`：同步解析固定 ZIP，真实图片解码，严格配置、路径、条目、CRC 和字节预算校验。2～12 层由前到后编号，转换为 Android 从后到前绘制的内部配置。
- `POST /admin/variants/{id}/parallax-resource-versions`：绑定派生资产和源包；重复请求复用，替换建立新版本。修复原 API 只允许一个前景的限制，支持 1～11 个连续前景 ordinal。
- 所有管理资源版本回读包含 `sourcePackage`；手工旧资源为显式 null。原 ZIP 私有保存，公开目录不暴露源包信息或原始图层地址。
- V5 增加源包、图层、失败清理任务三表及版本来源外键；V1～V4 不改。SHA 唯一约束保证并发只保留一份，资产/来源/审计事务提交。重复上传先核验原对象和派生资产仍可用。
- 失败清理无法删除时，独立事务登记任务，每分钟重试最多 100 项；有业务引用的文件受保护。没有启用成功孤立源包的自动回收或删除端点。
- 当时编辑器曾提供三层示例 ZIP 和配置模板。WP-UI08 解耦后，管理后台不再持有字段级模板；当前示例与导出统一由 Web 模拟器维护。
- 按用户要求保留上传 60 秒、其他请求 15 秒。H5/App 源码和已有待验收修改不纳入本次提交；未重新打包 App。
