## 2. 完成内容

- 工具版本升级为 2.0.0，只导入和导出 `formatVersion=2`。
- 删除旧 `depth`、全局 `strength`、增强曲线和增益算法路径。
- 每层使用开放的 `offsetPercent` 位移比例和独立 `direction`；100% 对应一整屏，200% 对应两屏，只要求是非负有限数值。
- `maxAngle` 支持 `1°～75°`，从中立位置开始线性响应；预览平滑时间基准与 Android 一致。
- 二层默认采用前景 `8% / follow`、背景 `3% / reverse`；多层效果由制作人逐层配置，不按编号推断方向。
- 最后一层背景根据自身最大位移增加绘制范围并裁切，避免移动时露边。
- 正式 ZIP 保留每层原始文件扩展名、像素尺寸和图片字节，不静默降分辨率或重新编码图层。
- 工程保存格式升级到 `projectVersion=2`；旧 v1 工程和源包明确拒绝导入。
- 960px 以下默认收起两侧面板，打开一侧时自动收起另一侧，预览区保持完整宽度。

### API、数据库与管理后台

- 4D 源包只接受 `formatVersion=2`；导入时只识别画布尺寸、连续图层索引和文件结构。
- 上传 ZIP 内的 `config.json` 作为原始字节保存，正式安全包中的配置与模拟器导出文件逐字节一致。
- API 不解析、不改写，也不把 `offsetPercent`、`direction`、`scale`、`opacity`、`blendMode` 等算法字段拆成数据库列。
- 未知算法字段可通过隔离的导入测试验证原样存储；当前 Android v2 使用严格字段集合，因此正式包构建会拒绝带未知字段的配置。
- Flyway V6 清理未上线的 v1 测试源包及相关派生包，移除旧算法列；已提交的 V5 保持不变。
- 管理后台改为展示配置版本、图层数、画布尺寸、文件大小和完整 SHA-256，不展示或编辑动画参数。
- OpenAPI 升级到 `1.6.0`，管理 DTO 增加 `configFormatVersion` 并移除图层算法字段；端点数量保持 58 个，Schema 数量保持 86 个。

## 3. 验证结果

- `node wallpaper-tools/parallax-studio/test.mjs`：通过。
- 所有非素材脚本执行 `node --check`：通过。

- API MySQL/Redis 集成测试：12 个场景通过；包含 V1→V2→V5→V6 迁移、旧源包清理、v2 原始配置字节下发、未知字段导入后正式发布拒绝和 v1 拒绝。
- 管理后台：16 项测试、TypeScript 类型检查和生产构建通过；构建只保留既有分块体积提示。
- OpenAPI：Redocly、专项契约检查和 bundle 生成通过，结果为 58 个操作、86 个 Schema、141 个直接 Java 错误字面量。
- `git diff --check`、契约冻结文件 SHA-256 和运行时文件排除检查通过。

## 4. 发布边界

当前正式发布链路只允许 Android 已支持的 `formatVersion=2` 严格字段集合。后续增加算法字段时先升级 `formatVersion` 并完成 Android 与模拟器支持，再让 API 增加新版本和稳定结构识别。API 继续只处理 ZIP 安全、文件与稳定结构、存储、签名和交付，不校验效果参数。未执行生产发布、生产迁移或生产数据操作。
