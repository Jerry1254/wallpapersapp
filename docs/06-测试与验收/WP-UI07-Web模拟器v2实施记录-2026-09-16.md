## 2. 完成内容

- 工具版本升级为 2.0.0，只导入和导出 `formatVersion=2`。
- 删除旧 `depth`、全局 `strength`、增强曲线和增益算法路径。
- 每层改用 `offsetPercent`：正数跟随、负数反向、0 固定，允许 `-25%～25%`。
- `maxAngle` 支持 `1°～75°`，从中立位置开始线性响应；预览平滑时间基准与 Android 一致。
- 二层默认采用前景 `+8%`、背景 `-3%`；多层效果由制作人逐层配置，不按编号推断方向。
- 最后一层背景根据自身最大位移增加绘制范围并裁切，避免移动时露边。
- 正式 ZIP 保留每层原始文件扩展名、像素尺寸和图片字节，不静默降分辨率或重新编码图层。
- 工程保存格式升级到 `projectVersion=2`；旧 v1 工程和源包明确拒绝导入。
- 960px 以下默认收起两侧面板，打开一侧时自动收起另一侧，预览区保持完整宽度。
