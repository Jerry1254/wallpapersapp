# WP-UI08 4D 独立轴配置同步记录（2026-09-16）

## 结论

Web 模拟器、正式 Android 和共享 Schema 已统一到当前 v2 独立轴模型。Java、数据库与管理后台已完成一次性配置解耦：API 只校验稳定外壳，对算法字段和客户端版本不维护白名单；管理后台只上传模拟器导出的 ZIP，不再维护字段级示例。4D Lab App 仍是 WP-UI08 的下一项实现，本记录不把 Lab App 计为完成。

## 本次完成

- 全局角度拆为 `motion.maxAngleX` 与 `motion.maxAngleY`，默认均为 75°，范围均为 1～75°。
- 每层拆为 `offsetXPercent`、`offsetYPercent`、`initialOffsetXPercent`、`initialOffsetYPercent`；运动强度非负且无产品上限，初始位置可正负且无产品上限。
- `direction` 继续由每层共用；`fixed` 只关闭动态运动，初始位置仍生效。
- Web 和 Android 使用相同公式。背景保护缩放同时覆盖初始位置与两个轴的最大动态运动；正式图片不降采样。
- Web 模拟器升级到 2.1.0，参数面板、即时预览、工程保存和正式导出均使用新字段。
- Web 模拟器增加旧 v1 测试文件夹的导入期迁移。当前正式 App 只运行 v2，不保留旧运行时分支；API 将版本作为数据透传。
- 上传和正式发布共用 `ParallaxConfigEnvelopeValidator`，只读取 `formatVersion`、`canvas.width/height` 和连续的 `layers[].index`；其余 JSON 字段不透明透传。
- `formatVersion` 接受不低于 2 的整数，V7 只放宽数据库约束，不增加算法列；当前 Android 可运行哪些版本仍由模拟器和 Android 协同决定。
- 正式包内的 `config.json` 保持上传原始字节；未来版本和未知算法字段已覆盖上传、正式发布与字节一致性自动测试。
- 管理后台已移除 2/3/12 层固定模板及对应的 Java 示例生成器，页面改为引导直接上传 Web 模拟器导出的完整 ZIP。
