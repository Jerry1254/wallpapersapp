# WP-UI08 4D 独立轴配置同步记录（2026-09-16）

## 结论

Web 模拟器、正式 Android、共享 Schema、正式发布字段门禁和管理后台示例包已统一到当前 v2 独立轴模型。4D Lab App 仍是 WP-UI08 的下一项实现，本记录不把 Lab App 计为完成。

## 本次完成

- 全局角度拆为 `motion.maxAngleX` 与 `motion.maxAngleY`，默认均为 75°，范围均为 1～75°。
- 每层拆为 `offsetXPercent`、`offsetYPercent`、`initialOffsetXPercent`、`initialOffsetYPercent`；运动强度非负且无产品上限，初始位置可正负且无产品上限。
- `direction` 继续由每层共用；`fixed` 只关闭动态运动，初始位置仍生效。
- Web 和 Android 使用相同公式。背景保护缩放同时覆盖初始位置与两个轴的最大动态运动；正式图片不降采样。
- Web 模拟器升级到 2.1.0，参数面板、即时预览、工程保存和正式导出均使用新字段。
- Web 模拟器增加旧 v1 测试文件夹的导入期迁移。正式 App 和正式发布仍只接受当前 v2，不保留旧运行时分支。
- API 不解释算法数值，只把正式发布兼容门禁改为当前字段集合；管理后台示例 ZIP 和生成器同步更新。
