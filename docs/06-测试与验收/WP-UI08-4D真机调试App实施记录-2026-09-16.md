# WP-UI08 4D 真机调试 App 实施记录

**日期：** 2026-09-16
**状态：** 实现与自动验证完成，待用户真机体验验收

## 1. 交付范围

- 新增 `lab` Android flavor：应用名为“倾境壁纸·4D调试”，应用 ID 为 `com.qingjing.qingjing_wallpaper.lab`。
- Lab 与普通体验包复用同一套首页、分类、搜索、我的、教程、下载和 Android 原生渲染代码；只有 4D 详情路由不同。
- 4D 详情使用全屏 APP_PREVIEW 原始图层，支持随真机倾斜实时调整方向、水平/垂直运动强度、初始 X/Y、缩放、不透明度、混合模式与全局 X/Y 最大倾斜角。
- 参数修改只更新已加载的原生场景，不重新下载或解码图片。
- 未保存修改写入 App 私有草稿；右上角确认后一次保存全部参数，返回时提供保存、放弃或继续调整。
- 新增管理端 Lab 保存接口，保存时复用原图层资产，原子创建新配置资产、新资源版本、正式包和 APP_PREVIEW，然后切换当前版本。

## 2. 1.0 原资源详情预览

- 静态详情已从公开列表封面切换到 APP_PREVIEW 中的原始 `STATIC_IMAGE`，Android 按原分辨率解码并 `CENTER_CROP` 展示。
- 视频和 4D 继续使用 APP_PREVIEW 中的原 MP4、原图层和原配置。
- 三类详情都继续使用预览短票据、设备会话、加密包和用途隔离，没有新增公开原图 URL。

## 3. 本地联调环境

- 重建并启动当前 API：`127.0.0.1:8083`，契约 1.8.0。
- 启动只监听 loopback 的 HTTPS 代理：`127.0.0.1:8443 → 127.0.0.1:8083`。
- Android 测试 scope 包含 `.local`、`.internal` 和 `.lab`，不放开其他应用标识。
- 本地作品 3“4D 网格圆形”已用 v2 独立轴配置发布为资源版本 4，便于两个 APK 安装后直接测试。
- 未执行生产发布、生产数据操作或生产迁移。
