# WP-UI10 免费壁纸后台与 API 验收记录

**日期：** 2026-09-16

**范围：** Java API、MySQL V8、OpenAPI 1.8.0、管理后台
**结论：** 实现完成，未执行生产发布、生产迁移或生产数据操作

## 1. 已实现

- `wallpaper.access_type` 只允许 `REDEEM/FREE`，旧数据和新建默认值均为 `REDEEM`。
- 公开列表、公开详情、管理列表、管理详情和管理写入统一返回或接收 `accessType`；公开与管理列表支持组合筛选。
- 管理后台新建/编辑表单增加“需要兑换/免费”单选，列表增加获取方式标识和筛选。
- 免费作品可在无权益时申请 H5 占位描述和 Android 安全包票据；设备身份、请求签名、发布状态、平台兼容、安全包、限流和短时票据校验保持。
- 短时票据记录签发时的 `FREE/ENTITLEMENT` 授权。免费改回需兑换后，新票据立即要求权益，已签发免费票据在原 90 秒内仍可读取；作品下架、设备/凭据撤销或版本退役仍会使票据失效。
- 免费作品的误兑换保存 `WALLPAPER_FREE`、`quotaDelta=0`，不扣码、不建权益；管理后台兑换记录可显示和筛选该结果。
- 修改获取方式只更新作品乐观锁版本，不创建或替换资源版本，也不改写 4D 配置、安全包、历史权益和兑换记录。
