## 3. 真实浏览器联调

使用本地 Java API、MySQL、Redis 和 FileStorage 完成以下流程：

1. 错误密码登录显示“账号或密码错误”，不会进入管理区。
2. 正确登录进入工作台；刷新页面后通过 HttpOnly Cookie 恢复会话。
3. 创建一级分类“联调风景”并上传 PNG 图标，再创建二级分类“联调静态”；刷新后树结构、图标和数量仍存在。
4. 空壁纸提交显示标题、slug、分类、封面和原图的必填错误。
5. 创建静态壁纸“联调晨雾”，上传封面和高清原图并发布；列表显示 `2/2 已就绪`、`已发布` 和全平台变体。
6. 刷新壁纸列表后数据仍存在；下架后显示 `已下架`，重新发布后恢复 `已发布`。
7. 编辑已有资源历史的壁纸时，类型和平台选择被锁定；替换高清原图并再次发布成功。
8. 兑换码、兑换记录和设备权益页面只显示 WP-P08 接口等待状态，不再展示浏览器 Mock 数据。
9. 桌面列表将状态和资源完整度放在主要可视区域。移动端登录和工作台无横向溢出；导航可打开、遮罩关闭，选择页面后自动收起。
