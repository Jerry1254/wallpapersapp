# 倾境在线客服功能需求

用户可直接在壁纸 App 中咨询，客服可在管理后台和独立安卓客服 App 中回复。本次以已确认原型为交互参考，接入正式 Java API，消息、会话和素材由服务器保存。

## 一、概述

| 版本号 | 日期 | 作者 |
| --- | --- | --- |
| 需求稿 1.0 | 2026-10-09 | — |

### 1. 需求背景

现有 Android、iOS 和鸿蒙 App 的联系客服入口展示微信客服。用户需要离开 App 才能咨询；客服需要在电脑和手机上处理多个用户的问题。本功能用于小规模日常人工回复，免费使用，不依赖收费 IM 服务。

| 问题点 | 问题描述 | 当前影响 |
| --- | --- | --- |
| 咨询跳出 App | 当前仅提供微信联系 | 用户咨询步骤增加 |
| 回复分散 | 正式后台没有客服会话与素材模块 | 多会话处理和常用内容复用不便 |
| 发送结果不明确 | 新聊天功能必须区分成功、失败与结果未确认 | 用户可能漏发或重复发送 |

### 2. 需求目标

用户无需新增账号即可咨询。客服在电脑或手机中可以切换会话，看到未读消息，使用后台统一维护的图片、视频和快捷短语回复。

| 指标 | 当前状态 | 目标状态 |
| --- | --- | --- |
| 三端用户咨询 | 微信客服入口 | 可在 App 内发送文字、图片并查看回复 |
| 客服回复入口 | 无正式在线会话模块 | 后台与独立安卓客服 App 共用真实会话 |
| 发送确认 | 无在线消息实现 | 仅服务器保存成功后显示已发送；同一消息重试不重复入库 |
| 消息同步 | 无 | 前台正常网络下通常在 3 秒内收到，断网恢复后补齐历史 |
| 素材共享 | 无 | 后台增删改查，手机客服同步查询和使用 |

### 3. 需求范围

包含三端用户聊天、后台及独立安卓客服 App 的会话处理、素材和短语管理、API 与数据库契约、相关构建测试。

不包含离线推送、机器人、群聊、语音通话、客服分配、绩效统计、已读回执、多租户或新增角色体系。本次开发不直接执行生产发布、生产迁移或生产数据操作。

工程默认：沿用现有设备身份与管理员账号；现有微信联系方式保留为备用入口；客服手机端只提供素材选择，素材维护集中在后台。这些默认选择不增加注册流程或管理角色。

## 四、功能说明

### 功能 1 用户咨询与客服回复

用户从现有联系客服入口打开聊天；客服在后台或独立安卓 App 选择用户后回复。沿用设备身份识别同一安装的用户，无额外注册。不同设备不自动合并；卸载重装后不承诺恢复为同一会话。

```text
打开聊天 → 加载最近记录 → 输入文本或选择图片或客服素材 → 点击发送
  ├─ 服务器保存成功 → 显示已发送，对端同步收到
  ├─ 明确拒绝或上传失败 → 显示发送失败并保留重试入口
  └─ 超时、断网或响应丢失 → 显示结果未确认 → 查询原消息标识
      ├─ 服务器已有记录 → 显示已发送
      └─ 尚无记录 → 允许用原标识重试，服务器去重
```

文本和媒体一条一条发送。上传完成与消息发送成功分别确认，上传成功不等于消息已发送。选中的素材和短语先填入回复区，由客服点击发送。刷新或重启后未确认消息继续核对结果；未经服务器确认不得显示已发送，不自动丢弃失败内容。

| 状态 | 进入条件 | 退出条件 | 可见表现 |
| --- | --- | --- | --- |
| 草稿 | 输入或选择内容 | 发送或主动清空 | 内容留在输入区 |
| 上传中 | 开始提交文件 | 上传成功或失败 | 进度或上传中，防止重复点击 |
| 发送中 | 向服务器提交消息 | 保存确认、明确拒绝或超时 | 发送中 |
| 已发送 | 收到服务器保存确认或查询到同一消息 | 终态 | 已发送 |
| 发送失败 | 明确校验、上传或请求失败 | 手动重试 | 失败提示及重试 |
| 结果未确认 | 响应超时、连接中断或发送时进程退出 | 查到记录或重试确认 | 未确认，保留核对与重试入口 |

已发送表示服务器已保存，不表示对方已阅读。客户端生成唯一消息标识并持久保存，服务器对会话、发送方和此标识建立唯一约束；相同标识不同内容返回冲突。会话内按服务器顺序分页，重连按最后同步位置补齐，重复拉取不会产生重复气泡。

| 字段 | 类型 | 必填 | 限制 | 校验规则 | 错误提示 |
| --- | --- | --- | --- | --- | --- |
| 文本 | 文本 | 文本消息必填 | 1 至 2000 字符 | 去掉首尾空白后非空 | 请输入消息；消息不能超过 2000 字 |
| 消息标识 | UUID | 是 | 标准 UUID | 重试保持不变 | 消息标识无效，请重新发送 |
| 消息类型 | 枚举 | 是 | TEXT、IMAGE、VIDEO | 用户仅 TEXT、IMAGE，客服支持三类 | 消息类型不支持 |
| 图片 | 文件 | 图片消息必填 | 单张不超过 10 MiB | JPEG、PNG、WebP，校验实际内容 | 图片格式不支持或超过 10 MB |
| 视频 | 文件 | 视频消息必填 | 单个不超过 100 MiB，时长不超过 15 分钟 | 客服 MP4 素材，实际内容和时长校验 | 视频格式不支持、超过 100 MB 或 15 分钟 |
| 文件标识 | 系统生成标识 | 媒体消息必填 | 正整数 | 属于本会话或客服可用素材 | 图片或视频不可用，请重新选择 |

| 场景 | 文案 |
| --- | --- |
| 空状态 | 您好，请描述您的问题，也可以发送截图 |
| 加载中 | 正在加载聊天记录 |
| 成功 | 已发送 |
| 失败 | 发送失败，点击重试 |
| 身份失效 | 连接验证失败，请重新连接；客服登录过期，请重新登录 |
| 网络异常 | 网络连接异常，恢复后将继续同步；发送结果未确认，请核对或重试 |

| 异常 | 触发条件 | 处理 | 反馈 |
| --- | --- | --- | --- |
| 响应超时 | 文本请求超过 15 秒 | 保留标识与内容，核对服务器记录 | 发送结果未确认 |
| 上传失败 | 格式、大小或网络失败 | 不生成已发送消息，保留选择并可重试 | 上传失败，请重试 |
| 文件预览失败 | 链接失效或网络异常 | 重新获取授权访问地址，可手动重试 | 内容暂时无法加载 |
| 重复提交 | 同一标识再提交 | 返回原保存结果 | 一个气泡，不重复入库 |
| 身份失效 | 设备凭据或管理员会话失效 | 停止同步，重连或登录后核对未确认内容 | 身份失效提示 |

### 功能 2 多会话处理与提醒

后台和手机客服共享会话列表。默认按最后消息从新到旧显示，支持搜索、全部或未读、分页和会话切换；每个会话独立保留草稿。前台新消息显示未读或提示，并提供可关闭的声音提醒。手机客服后台或锁屏后不保证及时提醒，回到前台补齐记录。

```text
打开客服列表 → 搜索或筛选 → 选择用户 → 同步记录 → 回复
移出会话 → 确认
  ├─ 取消 → 保持原列表
  ├─ 成功 → 隐藏会话，保留历史，切换下一会话或显示空状态
  └─ 失败 → 保持原列表并提示重试
隐藏后
  ├─ 用户仅打开 App 或聊天页 → 不恢复列表
  └─ 用户新消息保存成功 → 恢复列表并产生未读提醒
```

| 状态 | 进入条件 | 退出条件 | 可见表现 |
| --- | --- | --- | --- |
| 可见未读 | 用户新消息保存 | 客服实际显示相应记录并确认读取位置 | 未读数字 |
| 可见已处理 | 客服打开并读取记录 | 用户新消息或移出 | 正常列表项 |
| 已移出 | 客服确认删除 | 用户新的消息保存 | 列表隐藏，历史仍在 |
| 同步异常 | 网络或登录失效 | 网络和身份恢复 | 保留已有列表并显示异常 |

客服电脑和手机共用读取位置：一个端已打开的记录在另一个端也不再计未读。新消息到达与读取确认并发时，只清除实际已显示的位置，不能清除后来到达的消息。移出会话不撤回消息，也不影响用户查看历史。客服旧消息的迟到确认不能恢复已移出会话。

在线状态只向客服展示，表示用户聊天页面近期保持前台连接；页面关闭或连接失效后自动转为离线，不代表用户的整台手机是否联网。用户端不展示客服在线状态。

| 字段 | 类型 | 必填 | 限制 | 校验规则 | 错误提示 |
| --- | --- | --- | --- | --- | --- |
| 搜索词 | 文本 | 否 | 最多 100 字符 | 按会话编号或显示名称搜索 | 搜索内容不能超过 100 字 |
| 筛选 | 枚举 | 是 | ALL、UNREAD | 仅列出未隐藏会话 | 筛选条件无效 |
| 读取位置 | 正整数 | 是 | 已存在的服务器消息编号 | 属于当前会话，仅单调向前 | 聊天状态已变化，请刷新 |

| 场景 | 文案 |
| --- | --- |
| 空状态 | 暂无会话；没有找到匹配会话 |
| 加载中 | 正在加载会话 |
| 成功 | 会话已移出列表 |
| 失败 | 操作失败，请重试 |
| 权限不足 | 登录已过期，请重新登录 |
| 网络异常 | 暂时无法同步，网络恢复后重试 |

| 异常 | 触发条件 | 处理 | 反馈 |
| --- | --- | --- | --- |
| 列表很多 | 超出每页 50 条 | 分页加载并保留筛选 | 加载更多 |
| 全部移出 | 无可见会话 | 不显示无效聊天输入区 | 暂无会话 |
| 搜索无结果 | 不匹配 | 保留搜索输入 | 没有找到匹配会话 |
| 会话操作超时 | 超过 15 秒 | 保持内容并查询当前状态 | 操作结果未确认，请刷新 |
| 前后台切换 | 客服或用户页面暂停 | 停止轮询，回到前台续传 | 连接恢复后更新记录 |

### 功能 3 素材及快捷短语管理与同步

后台素材库分为图片、视频、快捷短语，沿用创作台式分类、搜索和预览布局。客服可新增、编辑、查询和删除；手机客服只查询、预览、选择。手机使用服务器数据，跨设备同步，不再依赖原型的浏览器本地存储。

```text
后台选择分类 → 搜索或新增或编辑 → 校验与上传 → 保存
  ├─ 成功 → 后台列表更新，手机下次同步或打开面板立即获取最新内容
  └─ 失败 → 保留表单，提示具体原因，可重试
删除 → 确认
  ├─ 取消 → 内容保持
  └─ 成功 → 各端选择列表移除，已发送历史仍可查看
手机选择素材或短语 → 填入回复区 → 人工点击发送
```

| 状态 | 进入条件 | 退出条件 | 可见表现 |
| --- | --- | --- | --- |
| 编辑中 | 新增或编辑 | 保存或取消 | 表单及原内容 |
| 保存中 | 校验通过并提交 | 成功或失败 | 保存中，按钮防重复 |
| 可用 | 服务器保存完成 | 编辑或删除 | 各端可选择 |
| 已删除 | 删除保存成功 | 终态 | 选择列表隐藏，历史引用保留 |
| 修改冲突 | 两个端修改同一版本 | 刷新后重新编辑 | 提示刷新，不能覆盖他人修改 |

媒体编辑可只改名称或备注，替换文件后新消息使用新文件，旧消息保留原文件。短语插入现有草稿时保留原文本，超过 2000 字时提示并停止插入。删除素材不删除聊天历史引用的文件；用户不能获取其他会话图片或查询客服素材库。

| 字段 | 类型 | 必填 | 限制 | 校验规则 | 错误提示 |
| --- | --- | --- | --- | --- | --- |
| 名称 | 文本 | 是 | 1 至 60 字符 | 去掉首尾空白后非空 | 请输入名称；名称不能超过 60 字 |
| 备注 | 文本 | 否 | 最多 200 字符 | 普通文本 | 备注不能超过 200 字 |
| 短语内容 | 文本 | 短语必填 | 1 至 2000 字符 | 去掉首尾空白后非空 | 请输入短语内容；不能超过 2000 字 |
| 图片或视频 | 文件 | 新建媒体必填 | 同聊天文件限制 | 实际内容与分类匹配 | 请选择有效图片或 MP4 视频 |
| 搜索词 | 文本 | 否 | 最多 100 字符 | 名称、备注、短语正文匹配 | 搜索内容不能超过 100 字 |
| 修改版本 | 正整数 | 编辑删除必填 | 服务器版本 | 必须等于当前版本 | 内容已更新，请刷新后再编辑 |

| 场景 | 文案 |
| --- | --- |
| 空状态 | 暂无素材，请在管理后台添加；暂无快捷短语 |
| 加载中 | 正在加载素材 |
| 成功 | 已保存；已删除 |
| 失败 | 保存失败，填写内容已保留；删除失败，请重试 |
| 权限不足 | 登录已过期，请重新登录 |
| 网络异常 | 素材暂时无法同步，请重试 |

| 异常 | 触发条件 | 处理 | 反馈 |
| --- | --- | --- | --- |
| 上传超时 | 文件上传超过 60 秒 | 保留表单，不假报保存成功 | 上传超时，请重试 |
| 并发编辑 | 版本不匹配 | 拒绝覆盖，保留输入 | 内容已更新，请刷新 |

| 无权限访问 | 用户请求素材或其他会话 | API 拒绝 | 无权访问此内容 |

## 五、工程约定与验收

Java API 使用独立设备客服接口与管理客服接口，沿用设备鉴权、后台登录和写请求校验。MySQL 保存会话、消息、附件归属、素材与短语；Redis 仅用于临时在线状态和短时文件访问凭据；文件由现有存储 Adapter 管理。OpenAPI 与 Flyway 同步维护，运行时文件和登录凭据不进入 Git。

前台默认约每 2 秒同步消息，失败时逐步退避；切换页面或进入后台暂停，恢复时立即补齐。服务端请求量小且不使用收费 IM 服务。视频、图片需要经会话或管理员身份授权，不能仅靠可猜的文件编号访问。

实施顺序：API、迁移及消息可靠性测试 → 后台会话与素材模块 → 三端用户 App → 独立安卓客服 App → 跨端联调与构建检查。可独立验收的流程分别提交并同步远端 main。当前已有 1.0 说明与项目看板保持冻结。

验收至少覆盖：

1. 三端用户都能发文字和图片、查看客服文字图片和 MP4 回复，客服在线状态不出现。
2. 后台与手机客服可同时登录、切换用户、搜索和查看未读，回复不会发到切换后的其他会话。
3. 丢失发送响应后查询原消息可恢复已发送；连续重试只生成一条记录。
4. 发送中刷新或退出再进入保留待确认消息；失败消息和内容可重试。
5. 重连后补齐断网期间的消息，分页无重复，读取旧页不跳过新消息。
6. 移出会话不丢历史；用户仅打开页面不恢复；用户新消息恢复且有未读。
7. 会话全部移出、筛选无结果和身份过期时页面可正常使用与恢复。
8. 素材及短语增删改查可用；后台修改后手机同步；选择后需要主动发送。
9. 删除或替换素材不破坏旧消息；跨会话访问附件和未登录管理请求被拒绝。
10. 安卓客服 App 关闭、后台和锁屏不宣称支持离线提醒，回到前台能补齐消息。
11. 相关 API 测试、OpenAPI 校验、后台检查、Flutter 检查及三端构建通过后交付；测试与正式签名按既有工程规则处理。
