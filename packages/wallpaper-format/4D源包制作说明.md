# 4D 源包制作说明

## 文件结构

```text
wallpaper.zip
├── cover.jpg
├── config.json
└── layers/
    ├── 01.png
    ├── 02.png
    └── NN.jpg
```

`01` 是最前景，最后一张是完整不透明背景。图层必须连续编号、尺寸与 `canvas` 一致，数量为 2～12。前景使用带透明通道的 PNG/WebP，背景可以使用 PNG/JPG/WebP。`cover.jpg` 是列表缩略图。

## 当前 v2 配置

```json
{
  "formatVersion": 2,
  "canvas": { "width": 2048, "height": 2048 },
  "motion": { "maxAngleX": 75, "maxAngleY": 75 },
  "layers": [
    { "index": 1, "offsetXPercent": 15, "offsetYPercent": 10, "initialOffsetXPercent": 0, "initialOffsetYPercent": -2, "direction": "follow", "scale": 1.18, "opacity": 1, "blendMode": "normal" },
    { "index": 2, "offsetXPercent": 3, "offsetYPercent": 2, "initialOffsetXPercent": 0, "initialOffsetYPercent": 0, "direction": "reverse", "scale": 1, "opacity": 1, "blendMode": "normal" }
  ]
}
```

| 字段 | 约束 | 含义 |
|---|---|---|
| `motion.maxAngleX` | 1～75° | 水平达到满幅运动的倾斜角，默认 75° |
| `motion.maxAngleY` | 1～75° | 垂直达到满幅运动的倾斜角，默认 75° |
| `offsetXPercent` | ≥ 0，无产品上限 | 满幅水平位移；100 为一屏宽 |
| `offsetYPercent` | ≥ 0，无产品上限 | 满幅垂直位移；100 为一屏高 |
| `initialOffsetXPercent` | 有限数，无产品上限 | 中立姿态水平修正，负左正右 |
| `initialOffsetYPercent` | 有限数，无产品上限 | 中立姿态垂直修正，负上正下 |
| `direction` | follow/reverse/fixed | 两个轴共用的动态运动方向；fixed 不取消初始位置 |
| `scale` | 1～1.5 | 显示缩放 |
| `opacity` | 0～1 | 不透明度；最后背景必须为 1 |
| `blendMode` | normal/screen/add | 混合模式；最后背景必须为 normal |

Schema：[`parallax-source-v2.schema.json`](parallax-source-v2.schema.json)。正式链路只接受当前 v2。Web 模拟器可导入旧 v1 测试文件夹并一次性转换，但 Android 不运行旧格式。

API 检查 ZIP 安全、稳定结构、画布、图层编号与图片关系，原样保存正式 `config.json`。API 不计算或改写上述效果参数，管理后台也不提供参数编辑；效果调整在 Web 模拟器或 Lab App 完成。
