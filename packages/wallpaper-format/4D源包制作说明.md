# 4D 壁纸源包制作说明

4D 效果在 Web 模拟器中完成调整，然后导出一个 ZIP。管理后台只上传完整 ZIP，不在后台重新编辑动画参数。

## 固定目录

```text
wallpaper.zip
├── cover.jpg
├── config.json
└── layers/
    ├── 01.png    最前景
    ├── 02.png    中间图层
    └── NN.jpg    最后一层为完整背景
```

- 支持 2～12 层，编号从 `01` 连续递增；所有图层使用同一画布尺寸。
- 前景使用带透明通道的 PNG 或静态 WebP；最后背景必须完整不透明，可使用 PNG、JPEG 或静态 WebP。
- `cover.jpg` 是列表和详情展示的合成封面，不参与 4D 分层播放。
- ZIP 内直接放上述内容，不要再包一层外部文件夹。

## 方向与位移比例规则

每层分别配置运动方向和位移比例：

- `direction=follow`：跟随手机倾斜。
- `direction=reverse`：向相反方向移动。
- `direction=fixed`：固定不动。
- `offsetPercent`：满幅角度下相对屏幕轴长的位移百分比。`10%` 移动 `0.1` 屏，`100%` 移动一整屏，`200%` 移动两屏；只要求是非负有限数值，不设置产品上限。
- `0%` 或固定方向均不移动。

二层项目默认可使用前景 `8% / follow`、背景 `3% / reverse`。这只是起始构图；多层项目可以输入 100%、200%、300% 等更大的位移，软件不根据图层编号推断方向。

## config.json v2

```json
{
  "formatVersion": 2,
  "canvas": { "width": 2048, "height": 2048 },
  "motion": { "maxAngle": 75 },
  "layers": [
    { "index": 1, "offsetPercent": 15, "direction": "follow", "scale": 1.18, "opacity": 1, "blendMode": "normal" },
    { "index": 2, "offsetPercent": 5, "direction": "follow", "scale": 1.18, "opacity": 1, "blendMode": "normal" },
    { "index": 3, "offsetPercent": 3, "direction": "reverse", "scale": 1, "opacity": 1, "blendMode": "normal" }
  ]
}
```

| 字段 | v2 范围 | 含义 |
|---|---:|---|
| `canvas.width/height` | 512～4096 | 与每张图层的源像素尺寸一致 |
| `motion.maxAngle` | 1～75° | 达到每层最大位移所需的相对倾斜角 |
| `index` | 1～12 连续 | 与 `layers/NN` 文件对应 |
| `offsetPercent` | ≥ 0，无产品上限 | 满幅位移比例；100 移动一整屏，200 移动两屏 |
| `direction` | `follow` / `reverse` / `fixed` | 跟随、反向或固定 |
| `scale` | 1～1.5 | 图层显示放大系数 |
| `opacity` | 0～1 | 图层整体不透明度 |
| `blendMode` | `normal` / `screen` / `add` | 图层合成方式 |

正式 Android 壁纸按源图层分辨率解码，不静默降采样。背景显示时会根据实际最大移动量预留边缘，这是绘制阶段的显示放大，不会改写、压缩或降低源图质量。

Schema：[`parallax-source-v2.schema.json`](parallax-source-v2.schema.json)。当前链路只接受 v2，旧 `depth/strength` 或带符号位移配置不再导入或播放。

## 后台与 API 边界

按 API-008 改造后，API 检查 ZIP 和图片文件是否完整、安全，然后原样保存和签名 `config.json`。API 不校验 `offsetPercent`、`direction` 等效果算法，不判断效果好坏，也不转换为另一套内部字段。详见 [API-008](../../docs/04-接口设计/API-008-4D配置透传与管理后台改造方案.md)。
