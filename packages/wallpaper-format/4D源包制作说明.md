# 4D 壁纸源包制作说明

管理后台选择「4D 固定资源包」，上传一个 ZIP 即可。封面、图层和配置自动解析；填写标题、分类等信息后保存或上架。

## 可直接使用的样例

后台编辑器提供三层示例 ZIP 和 config 模板下载。仓库中的 `apps/admin-web/public/templates/` 还提供两层、十二层示例，均为合成山景素材，可以自由修改。

```text
wallpaper.zip
├── cover.jpg
├── config.json
└── layers/
    ├── 01.png    最前景
    ├── 02.png    中景
    └── 03.png    完全不透明的背景
```

解压三层样例，替换素材，保持相同文件名和尺寸，再选中 `cover.jpg`、`config.json`、`layers` 一起压缩。不要把外层文件夹一起压入 ZIP。

## 素材和配置

- 2～12 层，编号从 `01` 连续递增，最大编号为背景；所有图层与 config 画布尺寸完全一致，宽高均为 512～4096。
- 前景导出带透明通道的 PNG 或静态 WebP；背景必须所有像素完全不透明，可使用 PNG、JPEG 或静态 WebP。
- 封面固定 `cover.jpg`，必须真实 JPEG，宽高不超过 4096，最大 20 MiB。
- `depth` 越大移动越明显，从前到后不能增大；背景固定 0。`scale` 建议从 1.1 开始，放大可减少移动时露边。
- 每层只写 `index`、`depth`、`scale`、`opacity`、`blendMode` 五项；背景 `opacity=1`、`blendMode=normal`。
- `config.json` 使用 UTF-8，无 BOM；不要添加 `role`、`ordinal`，这两项由服务端生成。
- ZIP 最大 100 MiB，解压全部条目累计最大 85 MiB，最多 64 个条目；单层最大 50 MiB，config 最大 64 KiB；图层与转换后内部配置合计最大 64 MiB。
- 不接受动画、加密、符号链接、嵌套 ZIP、ZIP64 或需要 EXIF 旋转的图片。导出图片时应用旋转。

上传同一份 ZIP 会复用源包；替换素材时生成新的资源版本，已经发布的旧版本仍保留。未选择新 ZIP 时编辑标题、分类不会创建资源版本。

## 再生成样例

从仓库根目录运行 `java -Djava.awt.headless=true scripts/GenerateParallaxExample.java`（Java 17+）。脚本只生成固定合成素材，不读取业务数据或运行时上传资源。

源配置 Schema：`parallax-source-v1.schema.json`。Android 内部格式仍使用 `parallax-config-v2.schema.json`。
